# 値段設定を考えなおす ── 2026-08-23

前回、私が **2,000円／発売記念2週間1,500円** と決めました。
聞かれたので、あらためて調べて考えなおした結果を書きます。

## 結論

**2,000円は安いです。2,500円にしてください。**
そして **「2週間25%OFF」の構造の方が、値段そのものより問題**です。

---

## 1. BOOTH の実際の相場（今日確認）

| 商品 | 価格 |
|---|---:|
| NDK VST Plugin | 120円 |
| iR Reverb / iR Delay / iR Phaser | 各 500円 |
| 清楚ボイスNext（ボイチェン） | 500円〜 |
| ModuRadio（AMステレオ再現） | 1,000円 |
| **Vocalith（ボーカル系VST）** | **2,500円** |
| BARRIER | 6,000円〜 |
| EqualizerCompX / VocalCleanerX / RVC Realtime ほか多数 | **0円** |

**帯は 500〜2,500円。** そして VocalGzzio にいちばん近い **Vocalith が 2,500円** です。

### VocalGzzio が 500〜1,000円の側にいない理由

- 単発エフェクトではなく **チャンネルストリップ（8モジュール）**。1本で1チェーン置き換わる
- VST3 ＋ **単体起動アプリ** ＋ 配信出力 ＋ 取扱説明書
- 1年・v3.1・**自動検査451項目**
- **ぜんぶ日本語**。これは他にありません

**帯の真ん中ではなく、上端にいるべき製品です。**

## 2. 500円上げて損になるのは、20.4%売れなくなったとき

BOOTH の手取りで計算しました。

| 価格 | 手取り | 100本での手取り |
|---:|---:|---:|
| 1,500円 | 1,371円 | 137,100円 |
| 2,000円 | 1,843円 | 184,300円 |
| **2,500円** | **2,315円** | **231,500円** |
| 2,980円 | 2,768円 | 276,812円 |

> **2,500円は、本数が 20.4% 減るまでは 2,000円に勝ちます。**
> （2,500円で 80本 売れれば、2,000円で 100本 と同じ手取り）

日本語のボーカルチャンネルストリップに**直接の競合がいない**以上、
500円の差で買う人が2割も消えるとは思えません。

そして値段は **下げるのは簡単、上げるのは難しい**。
迷ったら高い方から始めるのが安全です。

---

## 3. 「2週間25%OFF」の3つの欠陥

ここが本当の問題です。

1. **いちばん人目につく2週間の値段が1,500円になる。**
   発売直後がいちばん見られます。その期間の表示価格が、
   そのまま「VocalGzzioは1,500円の製品」という印象になります。

2. **3週目が値上げに見える。**
   1,500円で知った人にとって、2,000円は「高くなった」です。
   実際には元に戻しただけでも、そう感じます。

3. **いちばん値段を気にしない人に割り引いている。**
   発売直後に買うのは、これまで無料で使ってくれていた人たちです。
   その人たちは 2,000円でも買います。割引が要るのは、
   3ヶ月後に初めて名前を聞く人の方です。

## 4. ★すでに「無料版（Lite）」を作ってあります

`CMakeLists.txt` にこう書いてあります。

```cmake
option(VOCALGZZIO_LITE "Build the free Lite edition (no pitch tools)" OFF)
```

**ピッチ系を外した無料版が、もうビルドできる状態です。**
これを使わない手はありません。

### 体験版（Trial）より、無料版（Lite）の方が強い理由

| | 体験版 | **無料版 Lite** |
|---|---|---|
| 中身 | 全機能・60秒ごとに音が下がる | ピッチ系なし・**制限なしで使える** |
| 使われ方 | 数回試して消される | **ずっと入れっぱなし** |
| 1年間無料だった人 | 「取り上げられた」 | **「残してくれた」** |
| 宣伝力 | ない | **使い続ける人が広めてくれる** |

そして **ピッチ補正は、歌ってみたの人がいちばん欲しい機能**です。
そこを有料側に置くのは、切り方として正しい。

### ただし、体験版にも役目があります

2,500円払う前に、**ピッチ補正の音を聞きたい**はずです。無料版では聞けません。

**→ BOOTH の無料商品を1つ作って、中に2つ入れる。**

```
【無料】VocalGzzio 無料版＋体験版
  ├ VocalGzzio_Lite_Setup.exe   … ずっと使えます（ピッチ系なし）
  └ VocalGzzio_Trial_Setup.exe  … 全機能を試せます（60秒ごとに音が下がる）
```

商品は **有料1つ＋無料1つの計2つ**。3つに分けると買う人が迷います。

## 5. 最終提案

| 項目 | 前回 | **今回** |
|---|---|---|
| 通常価格 | 2,000円 | **2,500円** |
| 発売記念 | 1,500円（2週間・25%OFF） | **1,980円（2週間・21%OFF）** |
| 無料 | 体験版のみ | **無料版Lite ＋ 体験版を1商品にまとめる** |

**1,980円**にする理由：
- 2,000円を切っていて、心理的に「2千円未満」に入る
- 520円お得。1,500円ほど安くない＝**値段の印象を壊さない**
- 3週目に 2,500円へ戻しても、「1,980円→2,500円」なら値上げ感が薄い

**あるいは、割引を一切やらない。**
1年間無料だったこと自体が、もう十分すぎる発売記念です。
「これまで無料で使ってくれた方へ」と正直に書いて 2,500円で出す方が、
筋が通っていて気持ちがいい、という考え方もあります。

## 6. 反対意見（自分で潰しておきます）

**「最初の50人がレビューを書く。安い方が人数が集まる」**
これは正しいです。実際、BOOTH で音源を売った人の記録では
5ヶ月110本で、**買った人から「安すぎる」と言われた**とあります。
つまり安くしても「安すぎ」と言われる。**値段では感謝されません。**

**「無名の個人が2,500円は強気すぎる」**
体験版で音を確かめられる以上、無名であることのリスクは買う側にありません。
確かめてから払えます。
