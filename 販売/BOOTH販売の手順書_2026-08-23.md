## 0. さきに ── 手順より先に、塞ぐ穴が3つあります

BOOTH のやり方自体は簡単で、**30分で店は開けます。**
ただ、いまの状態でそのまま並べると **1本も売れません。** 理由が3つあります。

| # | 穴 | いまの状態 | 塞ぎ方 | 費用 |
|---:|---|---|---|---|
| **1** | **製品版が GitHub でタダで配られている** | v3.1.0 のリリースに `VocalGzzio_Setup_v3.1.0.exe`（7.38 MB）が**そのまま付いている**。誰でも1クリックで落とせます | リリースの添付を**体験版だけ**に差し替える | 0円 |

| **3** | **JUCE を「AGPL の側」で使っている** | JUCE 8 は「JUCEライセンス」と「AGPLv3」の二択。いまは AGPL 側＝**ソース公開が条件**。閉じるなら JUCE のライセンスが要る | **JUCE Starter に登録**（無料・年商 $20,000 まで・**ソース非公開で商用販売OK**・スプラッシュ画面も不要） | **0円** |

## 4. 手順 ── ここから実際の操作

### 【準備するもの】

- [ ] **pixiv アカウント**（無いなら作る。無料）
- [ ] **メールアドレス**
- [ ] **振込先の銀行口座**（出金するときに必要。店を開くだけなら後でOK）
- [ ] **商品画像**（あとで作ります。§5）
- [ ] **`VocalGzzio_Setup_v3.1.0.exe`**（製品版）
- [ ] **`VocalGzzio_Trial_Setup_v3.1.0.exe`**（体験版・別商品として並べる）

### 【手順①】ショップを開設する（10分）

1. `booth.pm` を開く
2. 右上「**ショップを開設する**」
3. **pixiv アカウントでログイン**（無ければその場で作れます）
4. **ショップ名**を決める ── 提案：`G'zzio`
5. **ショップURL** を決める ── 提案：`gzzio.booth.pm`
   > ⚠ **URL は後から変えられません。** ここだけ慎重に
6. ショップの説明・アイコン・ヘッダーを入れる（あとで直せます）
7. 開設完了

### 【手順②】商品を登録する（20分）

1. ショップ管理画面 →「**商品を追加**」
2. **商品名**を入れる
   > `VocalGzzio（ボーカルグッジオ）— 日本語のボーカルチャンネルストリップ VST3【遅延0】`
3. **説明文**を貼る → `BOOTH商品ページ下書き.md` の本文をそのまま
4. **商品画像**をアップ（1枚目がサムネイル。§5参照）
5. **カテゴリ** → `ソフトウェア > 音楽制作`
6. **★AI生成作品の申告** → **「AI生成作品を含む」にチェック**
   （イラスト・マスコットが AI 生成のため。本体プログラムは手書きですが、申告は必要）
7. **価格** → `2000`
8. **商品の種類** → **「ダウンロード商品」**を選ぶ
9. **ファイルをアップロード** → `VocalGzzio_Setup_v3.1.0.exe`
10. 「**公開**」

### 【手順③】体験版を別商品として並べる（10分）

同じ手順で、**もう1つ商品を作ります。**

| 設定 | 値 |
|---|---|
| 商品名 | `VocalGzzio 体験版（無料）— まず音を確かめてください` |
| 価格 | **0円**（BOOTH は無料頒布ができます） |
| ファイル | `VocalGzzio_Trial_Setup_v3.1.0.exe` |
| 説明 | 「60秒ごとに0.6秒だけ音量が下がる／設定の保存なし。**それ以外は製品版と同じ**」＋製品版へのリンク |

> **体験版を BOOTH に置くのが大事です。** GitHub に置くと、買う人が BOOTH と GitHub を
> 行き来することになります。**同じ店の中で「試す→買う」が完結する形**にしてください。

### 【手順④】発売記念の割引をかける

> **★2026-09-04 訂正。ここは間違っていました。**
> 「BOOTH のセール機能で期間と割引率を指定」と書きましたが、
> **BOOTH にセール機能はありません。** ヘルプセンターの一次資料で確認しました。
>
> > 「イベント期間中のみ、特典をつけることや値引きをする機能はありません。」
> > — [BOOTHヘルプセンター](https://booth.pixiv.help/hc/ja/articles/360002164634)
>
> クーポン機能も、出品者が発行できるものは見つかりませんでした。
> BOOTH Apps は4つ（メッセージ一斉送信／販売期間設定／容量追加／シークレット公開・各550円/月）で、
> **割引のアプリはありません**。「販売期間設定」は売る期間を決めるだけで、値段は変えられません。

**やり方は1つだけ ── 値段を手で書き換える。**

1. **発売記念価格で出す**（例: 1,900円）
2. 終了日に、商品の編集画面で**価格を 2,500円に書き換えて保存**する

**必ずこの向き（安く出して、あとで上げる）にしてください。**
先に2,500円で売ってから下げると、定価で買った人が損をします。

### 書きかたの注意（景品表示法）

VocalGzzio は**まだ2,500円で1本も売っていません**。
その状態で「通常2,500円 → いまだけ1,900円」と書くと、
**実在しない値段を比較対象にした二重価格表示**になります。

安全な書きかたは「これから上がる」と書くことです。

- ○ **発売記念価格 1,900円（9月15日から 2,500円になります）**
- × 通常2,500円 → いまだけ1,900円
- × 定価2,500円のところ24%OFF

（私は弁護士ではありません。心配なら消費者庁の二重価格表示の考え方をご確認ください）

### 【手順⑤】売上を受け取る

1. 「**売上・振込**」→ 振込先を登録（銀行口座 or PayPal）
2. **振込申請**をする（自動では振り込まれません。**申請が必要**）
3. 3万円たまってから申請すると、手数料が売上に対して軽くなります
