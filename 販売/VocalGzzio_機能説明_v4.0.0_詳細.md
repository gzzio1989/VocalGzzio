## 1. これは何か

マイクに入った声を、**その場で**整えて出すプラグインです。Windows の VST3 と、
DAW なしで動く単体起動の2つの形が入っています。

いちばんの特徴は **追加の遅延が 0 サンプル**であること。
自分の声をヘッドホンで聴きながら歌っても、口と耳がずれません。
（遅延が増えるのは、音程補正・ボイス変換・ハモリを ON にしたときだけ。→ 8節）

つまみの数は **91個**（`pid ("…")` の数を数えた実数）ありますが、
ぜんぶ触る必要はありません。「使いかた」を選ぶと見る所が変わり、
プリセットを選ぶと大半は決まります。

## 3. はじめに「使いかた」を1つ選ぶ

`音の種類` で4つから選びます。**つまみの位置は動かず、見る所だけが変わります。**

| 選ぶもの | 中で何が変わるか |
|---|---|
| **うた** | 標準。こもりは 300Hz、サ行は 5〜9kHz を見ます |
| **アコギだけ** | こもりを 220Hz に。ディエッサーはサ行ではなく**フレットの擦れ音**をさがします。ピックおさえが効くのはここだけ |
| **しゃべり** | 配信・実況向け。言葉の聞き取りやすさ側に寄ります |
| **声とギター** | 弾き語り用（1本のマイクに声とギターが同時に入る）。こもりを 300 と 220 の**2点**、サ行を 5.2k と 3k の**2点**で見ます。和音が入るので**ピッチ補正・ハモリ・ボイス変換は切ります** |

> 出どころ: `PluginProcessor.cpp` の `src_mode`、`Tooltips.h` の `src_tip`

### 自動セットアップ（押すだけ）

- **トーク自動** … しゃべり声を約5秒分析して、こもり・キンキン・サ行を自動でEQ調整
- **うた自動** … 約8秒歌うと、音量・コンプ・EQ・サ行おさえ・ノイズ除去・ひびきまで歌用にまとめて設定

分析の結果で「明るめ（コンデンサー系に近い）」「暖かめ（ダイナミック系に近い）」
「バランスが良い」の3通りに書き分けて表示します。
部屋のノイズが多いときは「静かな状態で LEARN を押すとさらにクリアになります」と出ます。

## 4. 音の通り道

```
入口   マイク音量 → ジー音（ハム）取り → きょり（近接効果ならし）
消す   ローカット → ゲート → ノイズ除去（4帯域・学習つき）
整える こもり／きつさ → スマートEQ → なめらか → ピックおさえ
押さえる ピークコンプ → レベルコンプ → 音量キープ → サ行おさえ → ポップ → リップ → ことば
色づけ プレゼンス → エア → あたたかみ → のび → 艶
表現   息 → エモ → サビリフト
声を変える ボイス変換 → ユニゾン×5／ハモリ → 音程補正      ←ここだけ遅延が増える
空間   ダブラー → ひろがり → ディレイ → リバーブ／へや
キャラ メガホン → コーラス → ロボ声
出口   ダッキング → メイクアップ → ミックス
```

### 順番を入れ替えられる所が3つあります

| 切替 | 何をする | こんなとき |
|---|---|---|
| サ行おさえを前へ | ディエッサーを音量そろえより**前**へ | 圧縮がサ行に反応して音がゆれるとき |
| ととのえを後ろへ | EQを音量そろえより**後ろ**へ | 削った帯域で圧縮を動かしたくないとき |
| ひろがりを前へ | 空間系をキャラ声より**前**へ | ロボ声・メガホンに響きを後がけしたくないとき |

> 出どころ: `ord_deess` / `ord_eq` / `ord_space`

## 5. 機能を1つずつ

### 5-1. 入口

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **マイク音量** | -24〜+24 dB | 入口のトリム。小さいマイクを持ち上げる |
| **ジー音** | 0〜100% | 電源由来の「ジー」を取る（ハムキラー） |
| **きょり** | 0〜100% | マイクとの距離が変わって声の太さがブレるのを、ならす。近づくと低音が持ち上がる（近接効果）、はなれると細くなる、その**差だけ**を減らす。**いつもの近さを40秒ほどかけて覚える**ので最初は控えめに効く。目安 30〜60% |

### 5-2. 消す

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **ローカット** | 60〜220 Hz | ポップノイズ・マイクの振動・部屋の低いうなりを切る。既定 100Hz |
| **ゲート** | -80〜-20 dB | 歌っていない間のノイズを絞る。**-80dB で実質オフ**（既定） |
| **ノイズ除去** | 0〜100% | → 下の 5-3 |

### 5-3. ノイズ除去（この製品の要）

声を **4つの帯域**に分け（分割は 250 / 1200 / 5000 Hz の Linkwitz-Riley）、
帯域ごとに「ノイズの床」を見積もって、**声が無い帯域だけ**を下げます。
遅延は増えません。

- **LEARN（学習）** … 押してから **約1.5秒**の「無音（ノイズだけ）」を測り、
  あなたの部屋専用のノイズの床を作ります。黙って押して、静かに1.5秒待つだけ。
- **じどう学習（v4.0.0 から既定 ON）** … しゃべっていない間に床を測りなおします。
  配信の途中で PC のファンが速くなる・エアコンが入る、に自動でついていきます。
- 未学習でも自動追従で動きます。

内部の作り（`PluginProcessor.cpp` から）:

| もの | 値 | 意味 |
|---|---|---|
| 包絡の追従 | 立ち上がり 2ms / 戻り 60ms | 帯域ごとの山を追う |
| 学習の窓 | 1.5秒 | LEARN を押したあとに測る長さ |
| 採用する床 | 中央値 × 1.4 | 余裕を持たせる |
| 開く境目 | 床 × 2.5 | ここを超えたら声とみなす |
| 自動学習の速さ | 時定数およそ2秒 | じどう学習の追従 |
| 床の自然上昇 | +3 dB/秒 | 部屋がうるさくなったとき |

> ★ **既知の弱点（v4.0.1 で直します）**: 学習の窓が 1.5 秒しかないので、
> 部屋の音がゆっくり波打っていると、押した瞬間がたまたま谷だと床が低く決まります。
> 「低すぎる床を捨てる」門が無いため、それがそのまま採用されます。
> v4.0.0 では「じどう学習を既定 ON」にする応急処置で、
> 削れのばらつきを **7.67 dB → 2.40 dB** に抑えました。
> （出どころ: `tools/dsp_dnlearnrep` の出力。Learn を37秒ごとに30回押しながら30分の実測）

### 5-4. 整える

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **こもり** | -12〜0 dB | 200〜400Hz の「箱っぽさ」を削る。既定 -3dB |
| **きつさ** | -12〜0 dB | 2〜5kHz の刺さりを抑える。既定 -1.5dB |
| **スマートEQ** | 3バンド | 耳障りな共鳴を**その瞬間だけ**自動で抑える。自動／手動。手動は 120〜8000Hz を3点、深さ 0〜15dB、Q 0.5〜8。遅延なし |
| **なめらか** | 0〜100% | 耳にささる周波数を自動で見つけ、出た瞬間だけ削る。音程が動いても追いかける。目安 40〜70% |
| **ピックおさえ** | 0〜100% | ギターのピックが当たる「カッ」の頭だけを、飛び出したときに軽く下げる。**「アコギだけ」のときだけ**効く。目安 20〜40% |

### 5-5. 押さえる

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **ピークコンプ** | 0〜100% | 急に大きくなったピークだけを素早く抑える（1段目）。既定 35% |
| **レベルコンプ** | 0〜100% | 全体の音量差をなだらかに揃える（2段目）。既定 30% |
| **アタック／リリース** | 1〜60ms／30〜500ms | 圧縮の速さ。既定 8ms / 120ms |
| **音量キープ** | 0〜100% | フレーズごとの**ゆっくりした**音量差を、フェーダーを動かすように整える（目標へ±9dBまで）。無音や息つぎでは動かない |
| **サ行おさえ** | 0〜100% | 5〜9kHz のシビランスだけを検出して抑える。既定 35% |
| **ポップ** | 0〜100% | 「ぱ・ば行」の“ボフッ”だけを狙う。**突発的で、かつ低域が中域より強いときだけ**動くので、低い歌声の基音は残る |
| **リップ** | 0〜100% | **歌っていない静かなところ**の口の粘着音を消す。3〜4kHz に一瞬立つ音を見つけてその瞬間だけ高域を落とす。歌っている最中は絶対に動かない |
| **ことば** | 0〜100% | 「か・た・ぱ」などの子音のときだけ 2.6kHz を持ち上げる。伸ばした母音とサ行には効かない |
| **つぶさない** | ON/OFF | 張ったときだけ圧縮の効き始めを上げ、あたたかみ・のび・音量キープを控えめにする。いつもの声量では何も変わらない |

### 5-6. 色づけ

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **プレゼンス** | -6〜+9 dB | 4kHz 付近の芯・子音の輪郭。既定 +1.5dB |
| **エア** | 0〜9 dB | 12kHz 以上の空気感。既定 +2dB |
| **あたたかみ** | 0〜100% | 軽いサチュレーションで倍音を足す。既定 15% |
| **のび** | 0〜100% | 減衰部をなめらかに持ち上げる。声が小さくなるほど自動でサポート |
| **艶** | 0〜100% | 訓練された歌手が持つ 3kHz 付近の共鳴を足す。**母音のときだけ開き、サ行では数ミリ秒で引く**ので手でEQを上げたときのような刺さりが出ない。まず 30% から |

### 5-7. 表現（ここが VocalGzzio らしい所）

| 名前 | 何をするか |
|---|---|
| **息** | 小さい声のときだけ 4.5kHz 上をそっと持ち上げる。大きい声では動かないのでサ行が刺さらない |
| **エモ** | ロングトーンを検出して、ひびきとひろがりをふわ〜っと開く（約0.4秒伸ばすと開き始め、切ると素早く閉じる） |
| **サビリフト** | 歌の勢いからサビを自動で見つけて、ひろがり・かさね・やまびこ・ひびきをまとめて持ち上げる。Aメロに戻ると静かに元へ戻る |
| **こぶし／しゃくり守り** | 意図した装飾を、補正がつぶさないように守る |

### 5-8. 声を変える（★ここだけ遅延が増える）

| 名前 | 範囲 | 何をするか |
|---|---|---|
| **ピッチ** | -12〜+12 半音 | 声の高さを変える。フォルマントは保つので早回し声にならない |
| **フォルマント** | -12〜+12 半音 | 体格・性別感を音程と独立に変える |
| **5人ユニゾン** | 0〜100% | 声質の違う4人分を作って重ねる |
| **ハモリ** | 9種 | ユニゾン／上3度／下3度／上6度／下6度／上5度／3度+5度／おまかせ／反行 |
| **ハモだけ** | ON/OFF | 原音を消してハモリの2声だけを出す（別トラック録り用） |
| **ピッチ補正** | キー12＋スケール9 | クロマチック／メジャー／マイナー／ハーモニックマイナー／メジャーペンタ／マイナーペンタ／ブルース／ドリアン／ミクソリディアン。補正量 0〜100%（既定80）、速さ 0〜100%（既定30） |
| **基準ピッチ** | 415〜445 Hz | A の高さ |

**セッションモード** … この3つ（ピッチ補正・ボイス変換・ハモリ）をまとめて止め、
追加遅延を 0 サンプルに固定します。SYNCROOM などのオンラインセッション用。

### 5-9. 空間

| 名前 | 何をするか |
|---|---|
| **ダブラー** | ごく短い揺らぎを持った分身の声を左右に薄く重ねる |
| **ひろがり** | ステレオの広がり。モノラル合算時は中央に戻る安全設計 |
| **ディレイ** | やまびこ。ms指定／1/4／1/8ほかのテンポ同期、くり返し 0〜90%、ハイカット 1k〜12kHz、BPM 50〜300（DAW の BPM が優先） |
| **リバーブ 7種** | ノーマル／ルーム／プレート／ホール／チャーチ／スプリング／シマー |
| **へや 6部屋** | → 6節 |
| **ダッキング** | 歌っている間だけディレイとリバーブを自動で下げ、語尾や息継ぎで残響が立ち上がる |

### 5-10. キャラ声

メガホン（拡声器／ラジオ／ローファイ）、コーラス、ロボ声（リングモジュレーター、20〜800Hz）。
プリセット6種（もどす／ロボット／宇宙人／電話のむこう／悪役ボイス／こわれたスピーカー）。

### 5-11. 出口

メイクアップ（0〜18dB、既定3dB）／ミックス（原音とのブレンド、既定100%）。

### 5-12. 点検（音には一切さわらない）

- **ゼロ遅延をたしかめる** … 「はかる」を押すと**約1秒だけ出力を止め**、その間にテスト信号を通して
  実際の遅延を測ります。申告値・実測値・その差を出します。
- **名前ごとの設定** … トラック名（無ければ自分で打った名前）ごとに設定を覚えます。
- **不具合報告セットの書き出し** … 何が起きたかを伝えるための情報をファイルに出します。
  **ネットワークには何も送りません。あなたが送るときだけ届きます。**

## 6. へや ── v4.0.0 の目玉

リバーブタイプの 8番目以降が「へや」です。
**実在する寸法の部屋の反射を、その場で物理計算して作った残響**です。
録音した IR ファイルを買ってきたのではなく、このプラグインが計算で起こしているので、
権利関係が 100% クリアです。

| # | 部屋 | 寸法 (m) | 残響 (実測) | どんな音 |
|---|---|---|---|---|
| 1 | **おふろ** | 2.1 × 1.7 × 2.3 | **1.29 秒** | タイル張り。近くて明るく、よく返る。ハミングや練習に |
| 2 | **カラオケ箱** | 3.4 × 2.6 × 2.4 | **0.45 秒** | ソファと絨毯に吸われた短くて温かい響き。いつも歌っている場所の音 |
| 3 | **録音スタジオ** | 2.0 × 1.6 × 2.2 | **0.24 秒** | 吸音ブース。ほぼ響かないが、部屋の空気だけ残る |
| 4 | **ライブハウス** | 13 × 9 × 4.2 | **0.95 秒** | 中域が前に出るステージの反射。壁と人の気配 |
| 5 | **コンサートホール** | 30 × 21 × 13 | **2.07 秒** | 立ち上がりが遅く、低音が長く伸びる |
| 6 | **プレート** | （鉄板・部屋ではない） | **1.87 秒** | 部屋鳴りが無く、密度だけ足せる。歌の定番 |

> 残響秒は `tools/dsp_heya.cpp` 検査2 の実測値。寸法は `Source/Heya.h` の `RoomSpec`。

### どうやって作っているか

- **前半（〜80ms）**: 鏡像法。箱型の部屋に音源と両耳を置き、壁で跳ね返った音の
  到達時刻と大きさを1本ずつ計算します。
- **後半**: 帯域ごとに減衰の速さを変えたノイズの尾。「低音は長く・高音は短く」という
  部屋ごとの性格を作ります。左右は別のノイズなので、広がりが出ます。
- **音量を6部屋で揃えてある**ので、切り替えてもひびきの量の感じ方が変わりません。
- **部屋の切替は音声スレッドから安全**（10ms のフェードなので、切り替えても
  プチッと鳴りません）。

### なぜ追加遅延が 0 なのか

ふつうの畳み込みリバーブは、まとめて計算するために音を貯めるので遅れます。
へやは **Gardner 方式の分割畳み込み**です。

- 最初の 256 サンプルは**直接そのまま掛け算**する
- 残りは FFT で、**1ホップ先回りして**用意しておく

この2つを足すので、**DAW のバッファがいくつでも追加遅延は 0 サンプル**です。
（出どころ: `tools/dsp_heya.cpp` 検査1 が、直接畳み込みの結果と一致することを毎回確認しています）

**記憶の使用量**: 周波数の対称性（エルミート対称）を使って、
半分だけ持てば足りるようにしました。6部屋ぶん合わせて、48kHz で
**およそ 17.6 MB → 8.9 MB**（ほぼ半分）。音は1サンプルも変わりません。

> 出どころ: `Heya.h` の割り当て式（`numParts × NBINS × 4` と作業用の4本）から計算。
> NBINS を 512 から 257 に詰めた差です。

| 状態 | 追加遅延 |
|---|---|
| ふつうに使う（へや・リバーブ・コンプ・EQ・ノイズ除去・スマートEQ すべて含む） | **0 サンプル** |
| ボイス変換／ピッチ補正／ハモリ を ON にしたとき | **768 サンプル** |

768 サンプルは、サンプリング周波数で時間が変わります。

| サンプリング周波数 | 768 サンプルは何ミリ秒か |
|---|---|
| 44.1 kHz | **17.41 ms** |
| 48 kHz | **16.00 ms** |
| 96 kHz | **8.00 ms** |

> 出どころ: `gz::VoiceShifter` を実際に作って `latencySamples()` を読んだ値（2026-09-04 実測）。
> FFT の窓は常に 1024 点、ホップ 256 点なので 1024 − 256 = 768。

> ⚠ **この文書を書く途中で見つけた食い違い**:
> 画面のヒント（`vc_pitch_tip`）に「遅延約12ms」と書いてあります。
> 実際は 44.1kHz で 17.41ms なので、**表示のほうが約5ms 少なく言っています**。
> v1.9.6 まで窓が 512 点だった頃の文が残ったものと思われます。
> **音は正しく、文字だけが古い**（DAW への申告値は 768 で正しい）ので音に影響はありませんが、
> 「測った数字しか書かない」という方針に反するので v4.0.1 で直します。

CPU の数字は、この文書には書きません。**測っていないからです。**

## 10. 体験版との違い

体験版は **60秒ごとに 0.6秒だけ音量が下がります**。

- 下がる深さ: **約 -18 dB**（0.12倍。消音ではありません）
- 出入り: 0.15秒ずつのなめらかなフェード（プチッとは鳴らない）
- 最初のディップは**挿してから60秒後**（挿した瞬間ではありません）
- **体験版は設定を保存しません**（閉じると消えます）

機能の制限はこれだけです。音質・機能はすべて製品版と同じものを確認できます。

> 出どころ: `PluginProcessor.cpp` の `VOCALGZZIO_TRIAL` ブロック
