## 1. SHIP BLOCKER（これを潰すまで売らない）

### B-1. 取扱説明書が無い
いまユーザー向けの説明は tooltip と README だけ。有償では
**「困ったときに読む物」が同梱されている**ことが品質の一部です。
→ 提案: `docs/manual.html`（1ファイル・オフラインで開ける・スクショ入り）を
v3.0-e の tooltip 全面書き直しと同時に生成する。私が作れます。

### B-2. SmartScreen の説明が無い
署名なしの exe は、買った人の全員が
**「WindowsによってPCが保護されました」**を最初に見ます。
説明が無ければ「ウイルス？」→ 返金・低評価につながります。
- 恒久策の**署名**は §3 参照（日本の個人は現状選択肢が限られる）
- 当面は **商品ページとインストーラー冒頭に、スクショ付きで
  「詳細情報→実行」の手順を明記**する。BOOTH の個人ソフトでは標準的な対応です。

### B-3. 動作環境の表記が決まっていない
実測で言えるのは: Windows 10/11 x64 / VST3 / 単体起動。
検査済み: 44.1k/48k/96k/192kHz、ブロック長 17〜512、REAPER 風の投げ直し61回、
2個同時挿し、GUI 20Hz 描画下の締切 0 落ち。
**実機確認済みは REAPER と OBS(仮想ケーブル経由) だけ**なので、
商品ページには「動作確認: REAPER / それ以外のVST3ホストでも動作するはずですが
未確認」と正直に書くことを勧めます（Cubase 13 の終了問題を直した実績はv2.3.0）。

### B-4. 素材（マスコット・テーマ絵）の出どころ → **解決（Gemini製と確認・2026-08-18）**
ユーザー確認済み: 画像素材は **Google Gemini で生成**。対応は3つ:
1. **BOOTH の商品登録で「AI生成作品」を申告**する（未申告は通報→BANの事例あり）
2. 商品ページに **「イラスト・マスコット: AI生成（Google Gemini）」** と明記
3. ~~どのプランで生成したかを確認~~ → **有料プランで生成と確認（2026-08-19）。
   商用利用は規約上明確にOK。作り直し不要。** これで B-4 は完全にクローズ。
   ※SynthID（不可視透かし）は入るが販売の支障にはならない。

### B-5. 試用の道が無い → **解決（体験版を実装・2026-08-18）**
`build.bat trial` → `installer.bat trial release` で **VocalGzzio Trial** が出来る。
- **別の製品として入る**（.vst3もexeもAppIdも別名 → 製品版と共存・混線しない）
- 60秒ごとに0.6秒、なめらかに-18dB下がる（挿した直後は落ちない。60秒後から）
- **保存は完全ブロック**（DAWプロジェクトにもautosaveにも残らない）
- ヘッダに「体験版」表示、SAVE/LOADはグレーアウト+理由tooltip、起動時に案内文
- 検査 `dsp_trial` 常設（周期・深さ・なめらかさ・保存ブロック・autosave非生成）
※§6の当初案（20分で素通し）は採らなかった。素通しは「壊れた」と誤解される
失敗モードがあり、再起動で回避もできる。ディップは予告すれば誠実で回避不能。

## 2. ライセンス（ファイルを読んで確認した事実）

| もの | 実物 | 判定 |
|---|---|---|
| リポジトリ | `LICENSE` = **AGPL v3** | **販売は合法**（AGPLは有償頒布を許す）。条件: ソース入手先の明示（GitHubで満たす）＋本文の同梱 → **インストーラーに追加済み** |
| JUCE 8 | AGPLv3 で使用中 | オープンソースのまま売るなら**追加費用ゼロで適法**。ソースを閉じたくなったら有償ライセンスが必要（現行の JUCE 9 は Starter 無料=年商$20kまで/Indie $40月=年商$300kまで。JUCE 8 からの乗換割あり） |
| VST3 SDK | JUCE 同梱・GPLv3 側 | AGPLv3 アプリと両立（GPLv3§13）。商品ページに **「VST is a trademark of Steinberg Media Technologies GmbH」** の一文を入れる |
| フォント | `kawaii_font.ttf` = **Mochiy Pop One**（実物の name テーブルで確認）SIL OFL 1.1、`Resources/kawaii_font_LICENSE_OFL.txt` あり | 埋め込み・サブセット・商用OK。**OFL文書の同梱が条件 → インストーラーに追加済み** |
| 画像素材 | character.png ほか | **出どころ未確認 → §7 相談1** |

**AGPLで売る、の意味（正直に）:** 買った人はソースを見られ、再配布する権利も持ちます。
BOOTH で払われるのは「ビルド済み・インストーラー付き・サポート付き」への対価です。
個人開発の音系ではこの形の販売例は普通にあり、恥じることはありません。
ソースを閉じたくなった時が JUCE 有償ライセンスの検討時期です。
