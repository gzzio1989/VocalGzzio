## 1. 実測データから判明した「10月8日以降 1個も売れていない」6つの本当の原因

今日時点の公開ページ・動画再生数・ダウンロード数・リンクをすべて実測調査したところ、**「製品の機能不足」ではなく「導線の断絶と無料流出」** という決定的な穴が6つ見つかりました。

### 🚨 原因①：【本日即座に修正完了】GitHub Releases に「2,500円の製品版インストーラー」が無料で公開されていた＋READMEのBOOTHリンクが404リンク切れだった
- **起きていた事実**：
  1. `https://github.com/gzzio1989/VocalGzzio/releases` の `v4.8.0`・`v4.0.0`・`v3.1.0` に、体験版だけでなく **製品版の `VocalGzzio_Setup_v4.8.0.exe` / `v4.0.0.exe` がそのまま公開添付** されていました（BOOTHページ末尾のGitHubリンクから飛んだ人が無料で製品版を入手できる状態になっていました）。
  2. さらに GitHub トップの `README.md` 冒頭にある `[BOOTHの商品ページ]` リンクが **`https://gzzio.booth.pm/items/8208045`（404 Not Found・存在しないURL）** になっていました。
- **実施した修正（完了）**：
  - GitHub API 経由で `v4.8.0` / `v4.0.0` / `v3.1.0` から製品版 `.exe` を即座に削除し、最新の `v4.9.0` リリースには **無料体験版（Trial）のみ** を登録しました。
  - `README.md` の BOOTH リンクを正しい `https://gzzio.booth.pm/items/8764003` に修正し、公式サイト（`gzzio1989.github.io/apps/vocalgzzio/`）も `v4.9.0` に同期しました。

### 🚨 原因③：10月8日〜14日の「不具合・未確認の注意書き」と、10月15日〜20日の「6日連続アップデート（v4.4→v4.9）」による様子見

  - また現在の BOOTH 無料体験版ダウンロード欄では `VocalGzzio_v4.7.0_Mac_体験版.zip` と `VocalGzzio_v4.8.0_Windows_体験版.zip` のようにバージョン番号が混在して見えています。
