## 2. 診断（効く順）

### ★1. 見られる数がフォロワー数で頭打ちになっている

表示 200〜1,050 は、**717人の中で消化されている数字**です。外に一歩も出ていません。

Xで外に出る道は3つしかありません。

1. 誰かがリポスト・引用する
2. 検索やハッシュタグから来る
3. 返信の会話で、その人のフォロワーに見える

固定ポストは ①が3件、②はタグが大きすぎて数分で流れ、③は**返信0**。
つまり**外に出る仕掛けが1つも無い**状態です。伸びないのではなく、伸びる経路が繋がっていません。

### ★2. プロフィールが受け皿になっていない（いちばん大きい穴）

仮に投稿が跳ねても、飛んできた人が最初に見るのは

> 田んぼと畑とパスタとラーメン！を頑張っています

**ソフトを作っている人だと分かりません。** ヘッダも無地。名前も「グッジオ」だけ。
ここが閉じている限り、他をどれだけ直しても水は全部こぼれます。

### ★3. 1つの投稿に3製品を詰めている

読む人は「自分に関係あるか」を**1回**で判断したいのに、3回判断させられます。
しかも刺さる相手が別々です。

- VocalGzzio … 歌ってみた／配信／SYNCROOMで歌う人
- BandFixGzzio … バンドの音源を持っている人
- GuzzAmp … ベースを宅録する人

**同じ投稿で3人を狙うと、誰にも刺さりません。**

### ★4. 言葉が「作る側」のもの

「リアルタイムチャンネルストリップVST」「分解ミックスマスタリングアプリ」——
この言葉を知っている人は、**すでにプラグインを持っています**。無名の個人開発品を試す理由が薄い。

いちばん喜ぶ人は、こう言います。

- 「録った歌がこもる」
- 「自分の声だけ細く聞こえる」
- 「ベースをラインで録ると薄い」

**悩みの言葉で書けば、その人に届きます。**

### ★5. 音のソフトなのに、音が無い

固定ポストの判断材料はスクショ4枚だけ。**聞けないものは判断できない**ので、いいね8で終わります。
GuzzAmp には v1.8→v1.9 の比較MP3が3本あるのに、使われていません。

**Xは音声ファイルを貼れません。動画にする必要があります。**（→ 今回こちらで作りました）

### ★6. 画像が読めない

GUI全体のスクショは、スマホの一覧で**文字が完全につぶれます**。
画像の役割は「読ませる」ではなく「指を止めさせる」。
**1枚につき、大きな文字で主張1つ**。

### ★7. #拡散希望 は逆に効く

アルゴリズムは見ていません。見る人には「中身より拡散が目的」に映ります。**外してください。**
#DTM は有効ですが母数が大きすぎて数分で流れます。**小さくて具体的なタグ**のほうが届きます。

### ★8. リンクが本文にある

外部リンク付きの投稿は配信が絞られる、と言われています（Xの公式見解ではありません）。
なので**断定はしません。代わりに測ります**：リンクを本文に置く回と、最初の返信に置く回を
交互にして2週間。表示数を比べれば、この目で確かめられます。

### ★9. アカウントが「雑談の器」として学習されている

4.1万投稿の大半が日常です。Xから見れば「野球と日常の人」。
だから製品投稿も**日常として配られます**。野球1,054 > 製品910 はその結果です。

日常をやめる必要はありません（むしろ人柄は資産です）。ただし
**製品の投稿は、日常とは別の形にしてください**（画像・型・タグをそろえる）。

### ★10. いちばん強い素材を使っていない

私が毎回書いている開発ログ——「サフサフの原因は私の診断違いだった」「検査が嘘をついていた」
「倍音が49dB逆を向いていた」——は、**個人開発でいちばん伸びる種類の話**です。
完成品の告知より、直している過程のほうが読まれます。それがXには1つも出ていません。

### ★11. 717人は、実は"いい客"です

SYNCROOM／cluster／ツイキャスで**歌う人・弾く人**が中心のはずです。
VocalGzzio の客そのものです。**外の人を探す前に、目の前の717人に届く言葉に変えるほうが早い。**

## 3. 直す順番（上から効きます）

### 第1手：プロフィール（今日15分で終わります）

**名前**
```
グッジオ｜歌と録音の道具をつくる
```

**自己紹介（160字以内・そのまま貼れます）**
```
歌と録音の「こまった」を道具にしています。
VocalGzzio（声をととのえる）／BandFixGzzio（バンド録音をAIで分解しミックス）／GuzzAmp（ベース用プリアンプ）。
Windows・無料でためせます。
SYNCROOM・cluster・ツイキャスで歌とベース。田んぼと畑も。
```

**ヘッダ画像** → `X素材_プロフィールヘッダ.png`（今回作りました。アイコンで隠れる場所を避けてあります）

**固定ポスト** → 3本まとめをやめて、**1本に絞る**。いまなら GuzzAmp の音くらべ動画。

### 第2手：投稿の型を決める

1. **1投稿1テーマ**（製品も1つだけ）
2. **1行目は悩みの言葉**（「録った歌がこもる」）。製品名は2行目以降
3. **画像は大きな文字で主張1つ**。GUI全体は貼らない
4. **リンクは最初の返信**（本文と交互に試して測る）
5. **タグは2〜3個**。#拡散希望 は使わない
6. **数字を1つ入れる**（「6.55dB→4.46dB」「768サンプル→0」）。数字は止まる

### 第3手：出す順番

いま**いちばん強いのは GuzzAmp** です。理由は3つ。

- 音のBefore/Afterが**すでにある**（聞ける＝判断できる）
- 「安い音の正体を測ったら49dB逆だった」という**話が面白い**
- ベースの宅録は、歌より**競合が少ない**

VocalGzzio は「SYNCROOMで歌う人」に絞って、717人に向けて出すのが早いです。

## 4. ハッシュタグ（相手ごとに変える）

**基本ルール：2〜3個。多いほど薄まります。#拡散希望 は使わない。**

| 相手 | タグ |
|---|---|
| 歌ってみた・宅録 | `#歌ってみた` `#宅録` `#ミックス` |
| SYNCROOM の人（＝いまのフォロワー） | `#SYNCROOM` `#宅録` |
| 配信・Vtuber | `#配信者と繋がりたい` `#マイク` |
| ベース | `#ベース` `#宅録` `#DTM` |
| 開発の話（個人開発界隈） | `#個人開発` `#JUCE` `#DTM` |

**使わない**：`#拡散希望`（効かない・印象が悪い）、タグ4個以上、`#DTM` 単独（母数が大きすぎる）

### ★動画を作るときに見つけたこと（大事）

配布物の比較MP3をそのまま貼ると**不利になります**。測ったら、

- v1.9 のほうが **RMS で 5.7dB、ピークで 13.4dB 大きい**

つまり**「後のほうが大きい＝良く聞こえる」**が混ざります。耳の分かる人ほど
「音量そろえてないやん」と言い、いちばん届けたい層の信用を落とします。

今回の動画は**両方をRMSで0.0dB差にそろえ、画面にもそう書いてあります**。
そろえた上でまだ違って聞こえるなら、それは本物の差です。
