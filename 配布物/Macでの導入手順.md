# VocalGzzio のMacへの導入

macOS 11以降のApple Silicon・Intel両対応版です。VST3、AU、単体起動アプリを同梱しています。版番号と製品版・体験版の区別は同梱の「配布情報.json」で確認できます。

現在BOOTHで配布している4.3.1は、Appleの開発元証明書による署名と公証を受けていません。付与しているアドホック署名は、開発元の確認に使う署名ではありません。Macの保護機能によってインストール・起動・プラグインの読み込みが拒否される場合があります。これは配布側で解決する必要がある課題であり、警告が出ない配布物への対応はまだ完了していません。

Mac実機での導入・マイク入力・Logic Proでの動作確認も未完了です。購入前に無料体験版で導入から音声処理まで確認してください。購入済みの方は、BOOTHの購入履歴からWindows版・Mac版を追加料金なしでダウンロードできます。

## どのファイルを使うか

| やりたいこと | 使うもの |
| --- | --- |
| Logic Proなどで使う | AU形式の `VocalGzzio.component`。下記の場所に導入し、録音ソフトの中から読み込みます。 |
| VST3対応の録音ソフトで使う | `VocalGzzio.vst3`。下記の場所に導入し、録音ソフトの中から読み込みます。 |
| 録音ソフトを使わず単体で起動する | `VocalGzzio.app`。導入後、このアプリを開きます。 |

`.component` と `.vst3` は録音ソフトに組み込む部品です。単体で開くアプリではないため、Finderでダブルクリックして起動しないでください。体験版のファイル名には「Trial」が付きます。

## インストーラーで入れる

1. 録音ソフトと古いVocalGzzioを終了します。
2. ZIPを展開し、「未公証.pkg」で終わるインストーラーを開きます。
3. 表示を確認してインストールします。管理者の認証が必要です。
4. 録音ソフトを再起動し、プラグインを再スキャンします。Logic ProではAU、VST3対応ソフトではVST3を使います。

配置先はVST3が `/Library/Audio/Plug-Ins/VST3/`、AUが `/Library/Audio/Plug-Ins/Components/`、単体アプリが `/Applications/` です。説明書とライセンスは `/Library/Application Support/Gzzio/` 内にも保存します。

## 自分だけに手動で入れる

「手動インストール」フォルダーの中身を次の場所へコピーします。末尾が `.vst3`、`.component`、`.app` の項目は、中身を取り出さず丸ごとコピーしてください。インストーラーと手動導入のどちらか一方で十分です。

| 中身 | 配置先 |
| --- | --- |
| VST3フォルダー内のプラグイン | `~/Library/Audio/Plug-Ins/VST3/` |
| AUフォルダー内のプラグイン | `~/Library/Audio/Plug-Ins/Components/` |
| 単体起動フォルダー内のアプリ | `~/Applications/` |

`~` は自分のホームフォルダーです。Finderの「移動」→「フォルダへ移動」で配置先を入力できます。フォルダーがない場合は作成してください。

## 「マルウェアが含まれていないことを検証できません」と表示されたとき

「Appleは、VocalGzzio.componentに……マルウェアが含まれていないことを検証できません」という表示は、Appleによる確認が取れないという警告です。この画面だけで、マルウェアが検出されたとは判断できません。一方で、安全性の確認が済んだことを示す表示でもありません。現在の未公証の配布方法が読み込みを妨げる原因になり得ます。[Appleの警告についての説明](https://support.apple.com/ja-jp/102445)

まず「完了」で閉じ、[公式BOOTHの商品ページ](https://gzzio.booth.pm/items/8764003)またはその購入履歴から入手したファイルか確認してください。入手元や改変の有無に確信がない場合は開かず、配布元にお問い合わせください。

### 入手元を確認したうえで、対象だけ許可する場合

利用者ご自身が内容を確認し、開くと判断した場合に限る操作です。必ず解決する方法ではなく、プラグインによっては対象の許可ボタンが表示されないこともあります。

1. インストーラーを使う場合は `.pkg`、単体で使う場合は導入済みの `.app` を開いた際の警告を確認します。AUは正しい場所に導入してから録音ソフトで読み込みます。許可のために `.component` を直接開く操作は行いません。
2. Macの「システム設定」→「プライバシーとセキュリティ」を開きます。古いmacOSでは「システム環境設定」→「セキュリティとプライバシー」です。
3. VocalGzzioの該当ファイル名を確認し、対象の「このまま開く」が表示される場合だけ選びます。確認画面でも、開く意思がある場合に「開く」を選びます。
4. プラグインの場合は、録音ソフトを再起動し、下記の手順でVocalGzzioだけを再スキャンします。

画面や操作の詳細は[Appleの案内](https://support.apple.com/ja-jp/102445)をご確認ください。Mac全体の保護機能を無効にする操作や、ターミナルでダウンロード時の保護情報を消す操作は案内していません。管理されたMacでは設定を変更できない場合があるため、管理者にご相談ください。

### Logic ProでAUが表示されない・読み込めない場合

1. `.component` がインストーラーの配置先、または上の手動導入先に丸ごと入っているか確認します。同じ製品版を両方の場所へ重複して導入しないでください。
2. 作業を保存してLogic Proを終了し、Macを再起動します。
3. Logic Proの「設定」（旧版では「環境設定」）→「プラグインマネージャ」でVocalGzzioを探します。
4. 対象が表示され、検証に失敗している場合は、そのVocalGzzioだけを選んで「選択項目をリセットして再スキャン」を実行します。開発元確認の警告が残っている場合、再スキャンだけでは解決しないことがあります。

[AppleのLogic Pro向け手順](https://support.apple.com/ja-jp/122179)も参照してください。対象が見つからない場合や再び検証に失敗する場合は、他のプラグインの設定を変更せず、下記の情報を添えてお問い合わせください。

### ここで操作を止めて問い合わせる場合

「破損している」「コンピュータに損害を与える」などの表示は、上の「検証できません」とは異なります。警告を回避せず使用を中止してください。「このまま開く」が見当たらない場合や、許可しても読み込めない場合も、繰り返し操作する必要はありません。

お問い合わせには、次の情報を分かる範囲で添えてください。

- Macの機種とmacOSの版番号
- 録音ソフトの名前・版番号、または単体アプリでの利用か
- VocalGzzioの版番号、製品版・体験版のどちらか
- 警告の画像と、どの操作で表示されたか
- インストーラーと手動導入のどちらを使ったか

単体アプリが開くものの音が入らない場合は、macOSのマイク使用許可と、アプリ内で選んだ入出力機器を確認してください。

## 体験版について

体験版は「VocalGzzio Trial」という名前で入り、製品版と共存できます。60秒ごとに0.6秒間音量が下がり、設定の保存と復元、プリセットの保存と読み込みが制限されます。音の処理自体は製品版と同じです。利用条件は同梱の使用許諾契約書をご確認ください。

## 削除するとき

録音ソフトと単体アプリを終了し、導入した場所にある該当のプラグインとアプリをゴミ箱へ移します。体験版には名前に「Trial」が付きます。製品版と体験版を取り違えないよう確認してください。ご自身で保存した音声やプリセットは削除する必要はありません。
