1. Get Sound in 60 Seconds (Choose A or B)

[A] OBS Studio / Streaming / Standalone App (No DAW Needed)

  1. Recommended: Run the bundled installer at the root of this ZIP folder (VocalGzzio_Setup_v5.5.0.exe, or VocalGzzio_Trial_Setup_v5.5.0.exe for the Free Trial). It installs the Standalone App, VST3 Plug-in, and offline manuals cleanly. (If Windows SmartScreen prompts "Windows protected your PC", click More info → Run anyway.)
  2. Option 1 — Direct OBS VST3 Filter (Easiest, zero virtual cables): In OBS Studio, right-click your Mic/Aux → Filters → + → VST 2.x/3.x Plug-in → select VocalGzzio (or VocalGzzio Trial).
  3. Option 2 — Standalone App + Loopback / External Virtual Cable: Launch VocalGzzio to use the built-in Karaoke BGM Player, 8 SE Pads, 📌 Mini-Bar, and Background Global Hotkeys. Route to OBS/Discord/VRChat via your audio interface's built-in loopback or an external virtual cable (VB-CABLE / Yamaha SYNCROOM Driver).
  4. Note on Virtual Driver Roadmap: To ensure full compatibility with the latest Windows 11 kernel protections and signature verification, bundling of a proprietary virtual driver has been postponed to a future roadmap release in favor of OBS native VST3, hardware loopback, and proven external virtual cables.

[B] VST3 / AU Plugin inside a DAW (REAPER / Cubase / Studio One / FL / Ableton)

  1. Run the bundled .exe installer at the root of this folder, or manually copy VocalGzzio.vst3 (VocalGzzio Trial.vst3 in Free Trial) from the VST3プラグイン folder into:
    C:\Program Files\Common Files\VST3\
    (On macOS, run the .pkg installer for AU, VST3 & Standalone).
  2. Restart your DAW, insert VocalGzzio on your vocal track, and click 🎤 うた自動.
