# VocalGzzio 4.4.0 変更記録（Gemini4Argon Edition / 2026年10月15日）

## 1. 独自倍音・立体音響DSP「Argon Velvet Engine」を新搭載
- **VELVET（母音追従・非対称三極管2次倍音 ＆ 胸声アンカー）**：母音帯域（220Hz〜1.8kHz）と歯擦音帯域（4.8kHz以上）のエネルギー比をリアルタイム追跡し、母音が鳴っている瞬間だけ非対称三極管（Triode）カーブによる温かい偶数次（2次）倍音と135Hzサブチェストの厚みを付加します。サ行やブレスが一切ザラつきません。
- **SILK AIR（クレスト保護つき14kHzシルク空気感）**：ピーク対RMS比（クレストファクタ）とサ行エネルギーを監視する動的ダンピング機能つき14kHzハイシェルフ励起。小声やささやきでは息づかいが華やかに開き、強いサ行では自動的に抑えられます。
- **3D BINAURAL HALO（モノラル完全互換・3D立体ハロー空間）**：4段の直交オールパス拡散フィルタと微細デチューン（±0.27Hz）により、左右へ逆位相で立体拡散成分を注入します。$(L+R)/2$ のモノラル加算時に拡散成分が数学的に完全相殺（位相キャンセリングゼロ）されるため、スマートフォンのモノラルスピーカーでも声が一切痩せません。

## 2. 「Argon 2D 声の重力場オーブ」と4種のVoice DNAターゲット
- 総合画面の中央デッキに、ドラッグ操作で声の距離感と質感を直感的に同時成形できる**「Argon 2D 声の重力場オーブ」**と、その周囲を公転する3つの倍音サテライト粒子（VELVET / SILK / HALO）、16セグメントLEDメーターバーを搭載しました（ダブルクリックでニュートラル0%へリセット）。
- ワンクリックでプロのターゲット声質を呼び出せる4つの**Argon Voice DNAボタン**（`★ 歌枠ベルベット` / `♥ ASMRささやき` / `✦ 透明ポップス` / `◆ 3Dバラード`）を追加しました。

## 3. 用途に合わせて変形する「4種のワークスペース画面構造」
画面上部の `[★ARGON / ♥LIVER / 🎛STUDIO / ◎従来]` ピルから、単なる色替えではなく操作盤の骨格そのものを切り替えられる4種のアーキテクチャを搭載しました：
- **`[★ ARGON]`（Argon Command Cockpit）**：中央に2D声質重力場オーブとRTAを据え、左翼に「01 整える＋02 声をつくる」、右翼に「5chテレメトリ計器＋03 空間をつくる」を配した画面遷移ゼロのコックピット配置。
- **`[♥ LIVER]`（V-Liver Stage Panorama）**：上段に2D声キャラメイク＆ステージモニターを並べ、下段に全12個の主要ツマミを五線譜リボン上に横一列で展開した配信・歌枠特化配置。
- **`[🎛 STUDIO]`（Studio 5-Slot Hardware Rack）**：左から右へ厳密なコンソール信号経路（PRE/CLEAN ➔ DYN/TONE ➔ ARGON MATRIX/RTA ➔ SPATIAL ➔ MASTER VU）が並ぶ5列ハードウェア・チャンネルストリップ配置。
- **`[◎ 従来]`（Classic 3-Card）**：従来の3カード配置。

## 4. ワンクリック省負荷「⚡軽量モード（ECO LITE MODE）」と職人技ノブ描画
- 画面上部の `[⚡軽量]` ピル（または「文字・見た目」ポップアップ）から、音声DSPの品質を100%最高品質に保ったまま、4096点FFTスペクトラム計算・背景パーティクル・半透明ガラス合成を休止し、UIタイマーを10Hzへ半減させる**軽量モード**を追加しました。
- 通常モードでは、アクティブ目盛りピン・先端コロナ発光・Vライバー12粒パールリング＆4芒星ジュエル・スタジオ36山ローレット刻み＆ルビー軸受など、テーマと画面構造に応じた高精度ベクター装飾を描画します。

## 5. 自動検査・配布物
- Windows / Mac 共通の自動検査を **51項目** に拡充し、全項目合格を確認しました。
- Windows版（VST3 / 単体起動アプリ）および Macユニバーサル版（macOS 11以降、Apple Silicon / Intel両対応、VST3 / AU / 単体起動アプリ / PKGインストーラー）の製品版・体験版を4.4.0へ更新しました。
