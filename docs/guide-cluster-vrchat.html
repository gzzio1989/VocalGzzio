1. なぜ cluster や VRChat で「音が消える」のか？（4つの原因）

原因起きる症状よく発生する機材・環境
① Windowsの「通信時の80%音量低下（ダッキング）」clusterやDiscordでマイク入力を開始した瞬間、Windowsが「通話中」と判定してワールドBGMやゲーム音を勝手に80%〜100%絞ってしまうすべてのWindows 10 / 11 PC（初期設定で有効になっているため）
② 排他ASIO / ASIO4ALL によるデバイス独占ロック単体アプリをASIOで起動した瞬間、オーディオインターフェースの出力が独占され、clusterやブラウザの音が一切出なくなるASIO4ALL、汎用ASIOドライバ、一部のエントリー機（UM2 / UMC22 / M-Track等）
③ サンプルレートの不一致（44.1kHz vs 48kHz）Windows既定が44.1kHzでアプリ側が48kHz（またはその逆）のとき、クロック切り替えで他アプリの音声ストリームが切断されるAG03MK2、UR22C、Scarlett、Rubix24/44、USBマイク各種
④ マルチバス（1-2 / 3-4）の不一致と二重返し出力が「3-4」や「Chat」バスに逃げて聞こえない、または自分の声がヘッドホンとアプリの両方から二重に返ってハウリングするRoland Rubix44、BRIDGE CAST、Elgato Wave Link、Sound Blaster GC7、SteelSeries Sonar

2. 『VocalGzzio v4.8.0』の3ボタンで1クリック解決する手順

『VocalGzzio v4.8.0』の単体起動アプリ（Standalone）を起動すると、画面上部に3つの専用修復ボタンが表示されています。

🛠 ①「cluster・通話 音消え一発修復」

クリックした瞬間に、Windowsレジストリの通信音量低下（80%ダッキング）を「何もしない」へ自動書き換えし、サンプルレートを48kHzへ揃えてオーディオ出力を瞬時に再同期します。

🌐 ②「全アプリ共存・共有モード」

ASIOで他のアプリの音が消えてしまう場合や、USBマイク・Meta Quest 3等をお使いの場合にクリックすると、全アプリの音が同時に鳴る「低遅延WASAPI共有モード」へ自動で切り替わります。

🎧 ③「自分の耳への返しミュート」

clusterやVRChat、OBSへ送る仮想マイク（「ライン (VocalGzzio Driver (WDM))」）には美しいエフェクト声を送り続けながら、自分のヘッドホンへの直接返しだけをミュートして二重聞こえを防ぎます。

3. cluster / VRChat 側のマイク設定（たった1箇所選ぶだけ！）

  1. 『VocalGzzio』単体アプリを起動し、お好みの声質（🎤歌枠、☕ゆるふわ、または「🎯5秒AI声質診断」）を選びます。
  2. 『cluster』または『VRChat』『Discord』の設定画面を開きます。
  3. マイク（入力デバイス）に ライン (VocalGzzio Driver (WDM)) を選びます。
  4. スピーカー（出力デバイス）には、普段お使いのヘッドホン・オーディオインターフェース（または Oculus Virtual Audio Device 等）をそのまま選びます。
これだけで、ワールドのBGMや仲間の声をクリアに聴きながら、ノイズ除去・音量均一化・空間IRリバーブ・ピッチ補正・5人ハモリ・絶叫セーフティガードが効いた最高の声をメタバースへ届けられます！

4. 「マイクが左耳（または右耳）からしか聞こえない」片耳問題の自動解決

オーディオインターフェースの IN 1（XLR端子）にマイクを挿すと左耳だけ、Focusrite Scarlett Solo（第3・第4世代）のようにXLR端子が IN 2 にある機種では右耳だけから声が鳴ってしまいます。
『VocalGzzio v4.8.0』の Auto Mono IN1-4 モード（初期設定でON）は、IN 1〜IN 4 のうち「人間の声が入っているチャンネル」だけを自動で追尾し、両耳の中央（L+R）へ揃えて出力します（MOTU M2/M4等の IN 3-4 にあるPCループバック音は自動で除外します）。
