# 4.2.1の修正内容

4.2.0試験版に寄せられた報告に対応した修正候補です。正式な配布開始はBOOTHの商品ページで案内します。

## ノイズ除去

- 起動直後に除去量を上げても、定常ノイズが長時間そのまま通る条件を修正しています。
- ノイズが大きいという理由だけで学習を拒否していた判定を見直し、音の周期性と変動を調べます。
- 小さい持続声をノイズとして学習し、声を削ってしまう条件を修正しています。
- 新方式で学習した大きめのノイズの設定が、保存・再起動後に破棄される問題を修正しています。
- 学習ボタンは除去量を変更しません。学習後も0％の場合、処理が切れている場合、測定中を区別して表示します。

## 表示・配布

- ブランド表示で日本語が残っていた説明や操作部品を英語に揃えます。通常の日本語表示は引き続き使えます。
- 総合画面の版番号を本体の版番号と一致させます。
- Mac版の最適化時に製品版／体験版の識別情報が消えて梱包に失敗する問題に対応します。

## 確認方法と限界

本体の音声処理に合成音を入力し、学習前後、起動直後、保存と復元、声の保護を比較しています。ホワイトノイズによる再現条件での改善を確認していますが、合成音による検査だけで、あらゆる声や機材での音質を保証するものではありません。

音程補正・ハモリには処理遅延があります。48kHzでは約42.6ミリ秒です。音声機器・録音ソフト・通信の遅延は別に発生します。

ノイズ除去では声とノイズが重なる成分を完全に分けられません。実際の歌声で原音と比較し、語尾や息が不自然にならない量に調整してください。
