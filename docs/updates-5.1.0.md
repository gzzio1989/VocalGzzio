# VocalGzzio 5.1.0 変更記録（Smart Stage, Zero-Lag Pitch & Studio Mic Edition）

公開日：2026年10月26日

---

## 1. 🎼 伴奏キー（調・長調/短調）＆ BPM 1秒自動解析エンジン（Auto-Key & Auto-Tempo Lock）

- **36音Goertzelクロマグラム × Krumhansl-Kessler 24調相関解析**：
  - BGMプレイヤーに曲を読み込んだ瞬間に、楽曲のメイン区間から12半音クロマエネルギーと100Hzオンセット包絡自己相関を高速解析し、**曲のキー（C〜B / 長調・短調の全24調）とテンポ（BPM 78〜172）**を即座に自動検出します。
- **伴奏キー変更（±6半音）への完全リアルタイム追従**：
  - BGMのキー変更スライダー（`-6〜+6`）を動かすと、検出されたキー表示も自動的に移調後のキーへ連動し、`[🎼 キー＆BPM自動反映]` ボタン1クリックでピッチ補正のキー・スケール（Major/Minor）とテンポ同期ディレイ/エコーのBPMへ一括反映します。

## 2. 📋 歌枠セットリスト（曲ごとの伴奏・キー・ボーカル除去・声質プリセット一括記憶）

- **`[➕ セトリ登録]` ＆ `[📋 セトリ(N曲)▼]` ワンクリック曲切り替え**：
  - 歌枠配信の前に歌いたい伴奏ファイル（最大32曲）を登録しておくと、曲ごとに **「伴奏ファイルパス・キー変更（±6半音）・原曲ボーカル除去ON/OFF・BGM音量・ダッキング量・解析済みキー＆BPM・声質プリセット（Argon 4軸＋主要DSP設定）」** を丸ごとセットリストとして記憶・自動保存します。
  - 配信本番中は `[📋 セトリ▼]` メニューから曲名をクリックするか `[⏭ 次の曲へ]` を選ぶだけで、伴奏とキー設定と声質が1秒で次の曲へ切り替わります（スタンドアロン版とVST3版の間でも自動同期されます）。

## 3. 🤖 サビ自動検知・オートブースト（Auto-Chorus Director）

- **両手フリーのサビ盛り自動演出**：
  - 伴奏BGMのエネルギー変化とボーカル声量をリアルタイム照合し、サビ突入を検知すると自動的に **Chorus Boost（声の芯+12%・高域シルク艶+18%・立体ハロー+22%・ダブラー厚み・ステレオ幅拡大）** を滑らかに発動します。
- **2.4秒ブレスホールド（息継ぎ維持）＆ 3段階ワンクリック切替**：
  - サビの途中で息継ぎ（ブレス）をしても2.4秒間はサビ演出が途切れず、Aメロや間奏に戻ると自然なフェードで通常バランスへ復帰します。
  - 総合画面フッター右デッキの `[★サビ盛]` ピルをクリックするたびに **`🔥サビ盛ON（常時） ➔ 🤖サビ自動検知 ➔ OFF`** をワンタッチで切り替えられます。

## 4. 💧 リップノイズ（口のペチャ音・舌打ち）瞬間除去（Zero-Latency Mouth De-Click）

- **ゼロ遅延・2次微分スルーレート突発クリック補間＋ダイナミック・ディクリック**：
  - 歌い出しや雑談・ささやき（ASMR）で最も気になる口元の「ペチャッ」「チッ」という唾液クリック音を、声の子音（タ行・カ行・サ行）のアタック感を一切損なわずにサンプル単位で滑らかに検出し、瞬間補間除去します。
  - ステージ＆スタジオパネルの `[💧 ペチャ音・リップ瞬間除去]` ボタン1クリックでON/OFFでき、除去されたクリックノイズの減衰量（dB）がリアルタイム表示されます。

## 5. 🎙️ ゼロ遅延・4大名機マイク・モデリング（Studio Mic Modeler）

- **追加遅延 0.0 ms（最小位相アナログ双二次フィルタ＋真空管偶数次倍音シェイパー）**：
  - お手持ちのダイナミックマイク・USBマイク・エントリーコンデンサーマイクの特性を、スタジオ名機の周波数特性＆倍音質感へリアルタイム変換します。
  1. **✨ 800G 真空管（モダン・チューブ・コンデンサー）**：10kHz以上の圧倒的なシルキーエアーと真空管の華やかな偶数次倍音。ポップス・アニソン・VTuber歌枠の王道。
  2. **👑 U87 王道（スタジオ標準コンデンサー）**：中域のふくよかな押し出しと密度の高いプロスタジオの定番トーン。
  3. **📻 SM7B 配信（ブロードキャスト・ダイナミック）**：75Hz以下の部屋鳴りを引き締め、近接時の温かい低域と刺さらない滑らかな高域で雑談・ゲーム実況・ロックに最適。
  4. **💎 ASMR 極艶（超近接ブレス・ウィスパー）**：息遣いと倍音の透明感を極限まで引き出す高解像度モード。

## 6. 🕰️ 歴代バージョン呼び出し・世代タイムマシン 全14世代拡張（`v1.0.0` 〜 `v5.1.0`）

- 初代 `v1.0.0` から `v5.0.0`、最新 `v5.1.0` までの **全14世代** を2列×7段グリッドからワンクリックで呼び出し可能になりました。
- 選択中の1世代のプレビュー画像のみをオンデマンド遅延読み込み（常駐メモリ 0 MB）し、旧世代を呼び出した際は後発DSP（v5.1のマイクモデリングやサビ自動検知を含む）を完全スリープ（0 CPU）させます。

## 7. 🎯 実質ゼロ遅延（0.08ms）ピッチ同期エンジン ＆「歌を上手く聴かせる」知能ピッチ制御 (`processSkilled`)

- **時間領域・ピッチ同期シフター (`TdPitchShifter`) による実質ゼロ遅延化（4サンプル ＝ 48kHzで約0.08ms）**：
  - FFT窓の蓄積を待たずに声の基本周期単位で波形を位相整合クロスフェード（TD-PSOLA / WSOLA）する専用エンジンを搭載。従来の42.6ms → 21.3ms から **約0.08ms（4サンプル）** へ劇的に短縮し、自分の耳への返しでも違和感が一切ありません。
  - 単一遅延線読み出し方式により原音と加工音の干渉（櫛形フィルタ）を原理的に排除し、**24時間連続の歌枠配信でも音質劣化ゼロ** を実証しました。
- **歌を自然に上手く聴かせる5つの知能ピッチ制御 (`PitchCorrection::processSkilled`)**：
  1. **ノート間ポルタメントとノート内即時制振の完全分離**：別の音符へ移る時は自然なレガートで繋ぎつつ、同じ音符内の不規則な声のふらつきは位相遅れゼロで瞬時にピタッと制振します（歌い出しの160msラグを解消）。
  2. **規則的ビブラート自動分離保護**：不規則なピッチ揺れは抑えながら、周期的な美しいビブラート（4.2〜9Hz）は検出して約96.5%そのまま自然に残します。
  3. **発声アタック16msのマイクロプロソディ保護**：子音から母音へ立ち上がる最初の16msの自然なイントネーションを保護し、ロボット声にならない生きた歌い出しを実現します。
  4. **ロングトーン重心ロック＆語尾のフラット垂れ防止（Anti-Sag）**：180ms以上続く伸ばし音や息が抜ける語尾でピッチが低く垂れ下がるのを自動的に支え、プロのような伸びやかな語尾を作ります。
  5. **ピッチ引き上げ連動・声芯（チェスト感）フォルマント補償**：高音が苦しくフラットした声を上へ補正した際、声が細く薄くならないよう240Hz声芯帯域の厚みをゼロ遅延で自動補償します。

## 8. ⚡ 超軽量・即応UI描画アーキテクチャ（オフスクリーンキャッシュ＆極小ダーティ矩形更新）

- **背景・天球・総合画面カードの静的イメージキャッシュ化**：

- **ドラッグ操作時の極小ダーティ矩形（`repaint(rect)`）局所更新**：
  - 2D Argon オーブや4本バー（`VELVET` / `FOCUS` / `SILK` / `HALO`）、各ツマミ、プリセットパレット操作時に変更箇所の最小矩形のみを再描画し、ドラッグ中の軽快で吸い付くような操作レスポンスを実現しました。
