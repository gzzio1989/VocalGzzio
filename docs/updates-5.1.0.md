# VocalGzzio 5.1.0 変更記録（Smart Stage & Studio Mic Edition）

公開日：2026年10月23日

---

## 1. 🎼 伴奏キー（調・長調/短調）＆ BPM 1秒自動解析エンジン（Auto-Key & Auto-Tempo Lock）

- **36音Goertzelクロマグラム × Krumhansl-Kessler 24調相関解析**：
  - BGMプレイヤーに曲を読み込んだ瞬間に、楽曲のメイン区間から12半音クロマエネルギーと100Hzオンセット包絡自己相関を高速解析し、**曲のキー（C〜B / 長調・短調の全24調）とテンポ（BPM 78〜172）**を即座に自動検出します。
- **伴奏キー変更（±6半音）への完全リアルタイム追従**：
  - BGMのキー変更スライダー（`-6〜+6`）を動かすと、検出されたキー表示も自動的に移調後のキーへ連動し、`[🎼 キー＆BPM自動反映]` ボタン1クリックでピッチ補正のキー・スケール（Major/Minor）とテンポ同期ディレイ/エコーのBPMへ一括反映します。

## 2. 🤖 サビ自動検知・オートブースト（Auto-Chorus Director）

- **両手フリーのサビ盛り自動演出**：
  - 伴奏BGMのエネルギー変化とボーカル声量をリアルタイム照合し、サビ突入を検知すると自動的に **Chorus Boost（声の芯+12%・高域シルク艶+18%・立体ハロー+22%・ダブラー厚み・ステレオ幅拡大）** を滑らかに発動します。
- **2.4秒ブレスホールド（息継ぎ維持）＆ 3段階ワンクリック切替**：
  - サビの途中で息継ぎ（ブレス）をしても2.4秒間はサビ演出が途切れず、Aメロや間奏に戻ると自然なフェードで通常バランスへ復帰します。
  - 総合画面フッター右デッキの `[★サビ盛]` ピルをクリックするたびに **`🔥サビ盛ON（常時） ➔ 🤖サビ自動検知 ➔ OFF`** をワンタッチで切り替えられます。

## 3. 🎙️ ゼロ遅延・4大名機マイク・モデリング（Studio Mic Modeler）

- **追加遅延 0.0 ms（最小位相アナログ双二次フィルタ＋真空管偶数次倍音シェイパー）**：
  - お手持ちのダイナミックマイク・USBマイク・エントリーコンデンサーマイクの特性を、スタジオ名機の周波数特性＆倍音質感へリアルタイム変換します。
  1. **✨ 800G 真空管（モダン・チューブ・コンデンサー）**：10kHz以上の圧倒的なシルキーエアーと真空管の華やかな偶数次倍音。ポップス・アニソン・VTuber歌枠の王道。
  2. **👑 U87 王道（スタジオ標準コンデンサー）**：中域のふくよかな押し出しと密度の高いプロスタジオの定番トーン。
  3. **📻 SM7B 配信（ブロードキャスト・ダイナミック）**：75Hz以下の部屋鳴りを引き締め、近接時の温かい低域と刺さらない滑らかな高域で雑談・ゲーム実況・ロックに最適。
  4. **💎 ASMR 極艶（超近接ブレス・ウィスパー）**：息遣いと倍音の透明感を極限まで引き出す高解像度モード。

## 4. 🕰️ 歴代バージョン呼び出し・世代タイムマシン 全14世代拡張（`v1.0.0` 〜 `v5.1.0`）

- 初代 `v1.0.0` から `v5.0.0`、最新 `v5.1.0` までの **全14世代** を2列×7段グリッドからワンクリックで呼び出し可能になりました。
- 選択中の1世代のプレビュー画像のみをオンデマンド遅延読み込み（常駐メモリ 0 MB）し、旧世代を呼び出した際は後発DSP（v5.1のマイクモデリングやサビ自動検知を含む）を完全スリープ（0 CPU）させます。
