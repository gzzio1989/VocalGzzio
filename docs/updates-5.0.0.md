# VocalGzzio 5.0.0 の変更点（All-in-One Live & Cover Production Suite）

公開日：2026年10月21日

## 1. ✨ 伴奏ボーカル除去（1クリック原曲カラオケ化）
- 内蔵カラオケ・BGMプレイヤーに、原曲（ボーカル入り音源）からメインボーカル帯域（160Hz〜4.2kHz）だけをリアルタイムに引き算する **「✨ 伴奏ボーカル除去」** スイッチ（フッター `✨ボカ消` ピル／ステージ＆スタジオ画面の専用スイッチ）を新搭載しました。
- 80Hz以下のベースやキック（低域）、および6.5kHz以上のシンバルやステレオの広がり（Side成分）を温存する **Mid/Side 帯域選択型センターキャンセラー** により、伴奏の迫力を損なわずに手持ちの原曲ファイルをその場でカラオケ伴奏化して練習・歌枠配信に利用できます。

## 2. 💿 -14 LUFS 自動音圧マスタリング ＆ 完パケFullMix同時書き出し
- 「🔴 1クリックWAV録音」および「⏪ 直前30秒さかのぼり保存」に、YouTube・ニコニコ動画・配信プラットフォームの標準ラウドネス規格（**-14.0 LUFS / -1.0 dBTP トゥルーピーク制限**）へ自動音圧調整するマスタリングエンジンを搭載しました。
- これまで書き出されていた2ファイル（加工済みの声 `_完成音(Wet).wav` と、外注MIX師へそのまま渡せる素の声 `_素の声(Dry_MIX用).wav`）に加え、内蔵BGMプレイヤーで伴奏を流しながら歌った場合は **3ファイル目として `_完パケMIX(-14LUFS).wav`（伴奏＋歌声の完成フルミックス音源）を同時書き出し** します。DAWを開かなくても、歌い終わった瞬間にそのまま動画投稿やSNSショート動画に使える完パケ音源が手に入ります。

## 3. 🔥 サビ1クリック華やか演出（Chorus Boost）
- 歌枠配信やカラオケのサビに入った瞬間、ワンクリックで声を一段前に押し出し、ダブリングの厚みとホール残響の広がりを自然にブーストする **「🔥 サビ演出（`★サビ盛`）」** トグルボタンを搭載しました。
- ON/OFF切り替え時には25msの滑らかなクロスフェード（エンベロープ補間）が働き、クリックノイズを一切出さずにAメロ・Bメロからサビへのドラマチックな展開を演出できます。

## 4. 👏 歌枠・VC盛り上げ 4種ライブSEポン出しパッド
- 外部サンプラーや効果音アプリを立ち上げなくても、歌い終わった直後や雑談MCのオチで即座に鳴らせる **4種類のステレオ効果音（SE）ポン出しボタン** を総合画面フッターおよび「🎯 ステージ＆スタジオ」画面に搭載しました。
  - **👏 拍手**：自然なステレオの広がりを持つ拍手＆歓声
  - **✨ キラ**：登場時や曲紹介を彩るクリスタル・ウィンドチャイム
  - **🥁 ジャン**：発表やオチを盛り上げるスネアロール＆シンバルクラッシュ
  - **🔔 ピンポン**：クイズや話題転換に使える明るい2音チャイム
- 鳴らしたSEは自分のヘッドホン（モニター）と配信・通話相手（`VocalGzzio Driver (WDM)` 等の外部ブリッジ出力）の両方へ自動でミックス送出されます。

## 5. 🕰️ 歴代バージョン呼び出し・世代タイムマシン（v1.0.0 〜 v5.0.0 全13世代）＆ オンデマンド省負荷設計
- 総合画面ヘッダーや詳細画面のバージョンバッジ（`🕰v5.0.0▼`）、または「文字・見た目」ポップアップ内の **`[🕰 歴代バージョン呼び出し (v1.0〜v5.0)]`** から、初代 `v1.0.0`（クリーム・フラット2列）や `v1.7.0`（ゆるふわパステル2列）、`v2.4.0`（かんたん1列モード）、`v4.3.3`（3ステップ総合画面）など **歴代13メジャー世代の画面構成・配色・DSP構成をいつでも呼び出せる「世代タイムマシン」** を搭載しました。
- **オンデマンド遅延読み込み（起動時メモリ増加 0 MB）**：全世代のデータを起動時に一括読み込みせず、ポップアップで選択した1世代のプレビュー画像だけをオンデマンド展開し、閉じると即座にメモリを解放します。あわせて実測部屋残響 `Heya` の6部屋IR合成および4種ライブSE波形生成も、実際に選ばれた部屋・押されたSEのみをオンデマンド合成する遅延初期化へ刷新しました。
- **世代別省負荷ゲート（Zero-CPU Sleep / 最大 -80% 負荷削減）**：過去バージョンを呼び出している間は、その世代に未搭載だった後発DSPステージ（Argon 2Dオーブ、オートミキサー、エモート表現、ピッチ補正・5人ユニゾン等）を自動的に完全スリープさせ、当時の軽快なCPU負荷（初代 `v1.0.0` 再現時は約80%削減）で動作します。

## 6. 3軸プリセットパレット刷新・タブレット＆太指タッチ操作エルゴノミクス・UI高速化
- **3軸ビジュアルカードパレット**：声質・発声（18種）、マイク・環境（16種：機種名に縛られない音響特性・部屋環境軸＋代表機種例併記）、曲調・ジャンル（16種：アニソン5細分化・ボカロ3細分化等）および「仕上がり（20種）」を、ホバー1秒プレビュー付きの大型カードパレットから直感的に選べるようにしました。
- **タブレット・太指タッチ操作対応**：総合画面フッターの「🎯 ワンタップ微調整ドック（`[➖] [➕] [↺初期]`）」、2段式「指上フローティング特大数値＆音変化ルーペ」、数値カプセルの左右端タップ微調整＆誤爆防止、指離し時のドリフト補正、EQグラフの56pxタッチ判定＆ダブルタップQ幅切替を搭載しました。
- **UI描画レスポンスの高速化と4種の表示スタイル・文字サイズ150%完全検証**：フォント文字列幅キャッシュとレイアウト差分ガードを導入し、画面切替・表示スタイル切替（「標準デザイン」「◉ くっきり大文字」「★ かんたん3ステップ」「● マット・具体表記」）・文字サイズ変更（80%〜150%）時の応答速度を大幅に高速化しました。
