01. アプリ別カラオケ取込 ＆ 1クリック音ズレ計測

仮想ケーブル不要で Chrome / YouTube カラオケ等の音だけを直接取り込み、ボーカル除去・キー変更±6・声ポケット調整を適用できます（二重再生によるフランジングも自動防止）。「自動計測」で往復遅延を実測し、声と伴奏のズレ（±300ms）も1クリックで揃えられます。

02. 伴奏コード追従ハモリ ＆ SNS動画書き出し

伴奏のリアルタイム和音（[C][Fm][E7]等）を追尾し、J-POP特有の借用和音や転調でもハモリが濁りません。歌った直後に X / YouTube（16:9）や Shorts / TikTok（9:16・加工前後比較可）用の -14 LUFS 調整済 .mp4 動画を直接保存できます。

03. 省電力設計・小型ミニバー ＆ 160機種対応

単一FFTハーモナイザと最小化時GPU休止で負荷を40〜70%削減。520×115pxの「配信ミニバー」や裏画面ホットキー、目に優しい19種類のテーマ切替、AG03 / Scarlett から USBマイク・Quest 3・cluster まで幅広く対応しています。

よくあるご質問（Q&A）— 歌枠配信者・活動者の方からよくいただく相談

ご質問回答
Q1. DAW（音楽制作ソフト）がなくてもOBSだけで歌枠配信できますか？はい、DAW不要です。 OBSのマイク音声フィルタから「VST 2.x/3.x プラグイン（VocalGzzio）」を直接読み込むだけで仮想ケーブル不要・低遅延で直結できます。また単体起動アプリ（VocalGzzio.exe）の内蔵BGMやSEも丸ごと送りたい場合は、オーディオIF内蔵ループバックや外部仮想ケーブル（VB-CABLE / Yamaha SYNCROOM Driver 等）で連携できます。
Q2. YAMAHA AG03 / AG06 や USBマイクでも使えますか？はい、すべて対応しています。 AG03MK2 / Scarlett / UR22C / MOTU M2 等はもちろん、AT2020USB-X / MV7+ / Yeti / QuadCast 等のUSBマイクでもそのまま使えます。AG03等の本体LOOPBACK切り忘れによるハウリングを自動遮断する安全ガードも内蔵しています。
Q3. OBSやYouTubeカラオケと声のタイミングがズレるときは？v5.5.0の「音ズレ補正（±300ms）」で解決できます。 「BGM・録音」内のスライダーまたは自動計測で、歌声または内蔵BGMを1ms単位で揃えることができます。
Q4. 配信中にOBSや歌詞画面を触りながら咳ミュートやMC切替はできますか？はい、可能です。 「ミニバー」で画面の隅に小さく常駐させるか、裏画面ホットキー（Ctrl+Shift+M 咳ミュート／F9 長押し咳ミュート／Ctrl+Shift+T 歌枠⇄MC切替）で裏画面のまま操作できます（全角かな入力中でも誤動作しません）。
