よくあるご質問（Q&A）— 歌枠配信者・活動者の方からよくいただく相談

ご質問回答
Q1. DAW（音楽制作ソフト）がなくてもOBSだけで歌枠配信できますか？はい、DAW不要です！ 同梱の「単体起動アプリ（VocalGzzio.exe）」と専用仮想ドライバ「ライン (VocalGzzio Driver (WDM))」が入っているので、OBSのマイク音声に「ライン (VocalGzzio Driver (WDM))」を選ぶだけで直結できます。
Q2. YAMAHA AG03 / AG06 や USBマイクでも使えますか？はい、すべて対応しています！ AG03MK2 / Scarlett / UR22C / MOTU M2 等はもちろん、AT2020USB-X / MV7+ / Yeti / QuadCast 等のUSBマイクでもそのまま使えます。AG03等の本体LOOPBACK切り忘れによるハウリングを自動遮断する安全ガードも内蔵しています。
Q3. 自分の耳への返しは遅れませんか？声が二重になりませんか？ゼロ遅延（追加遅延0.0ms）対応です！ またインターフェース本体のダイレクトモニターを使う場合は、画面上の「🎧自分の耳への返しミュート」を1クリックするだけで、OBSへはエフェクト後の声を送り続けながら自分の耳への二重返しだけを消せます。
Q4. カラオケ音源（インスト）がない曲でも歌えますか？キー変更は？はい！ 「🎵BGM・録音」に原曲ファイルを読み込んで「✨ボーカル除去」をONにするだけでその場でカラオケ伴奏化でき、±6半音のキー変更（歌声のピッチ補正キーも自動連動）も可能です。
Q5. 歌枠の曲間の「雑談（MC）」でエコー（リバーブ）をすぐ切れますか？はい！ 上部の「🎤歌枠 ⇄ 💬雑談MC」を1クリックするだけで、華やかな歌枠サウンドから聞き取りやすい雑談声へ瞬時に切り替わります。
