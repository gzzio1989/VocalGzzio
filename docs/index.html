よくあるご質問（Q&A）— 歌枠配信者・活動者の方からよくいただく相談

ご質問回答
Q1. DAW（音楽制作ソフト）がなくてもOBSだけで歌枠配信できますか？はい、DAW不要です！ OBSのマイク音声フィルタから「VST 2.x/3.x プラグイン（VocalGzzio）」を直接読み込むだけで仮想ケーブル不要・ゼロ遅延で直結できます。また単体起動アプリ（VocalGzzio.exe）の内蔵BGMやSEも丸ごと送りたい場合は、オーディオIF内蔵ループバックや外部仮想ケーブル（VB-CABLE / Yamaha SYNCROOM Driver 等）で連携できます。
Q2. YAMAHA AG03 / AG06 や USBマイクでも使えますか？はい、すべて対応しています！ AG03MK2 / Scarlett / UR22C / MOTU M2 等はもちろん、AT2020USB-X / MV7+ / Yeti / QuadCast 等のUSBマイクでもそのまま使えます。AG03等の本体LOOPBACK切り忘れによるハウリングを自動遮断する安全ガードも内蔵しています。
Q3. OBSやYouTubeカラオケと声のタイミングがズレるときは？v5.5.0の「⏱️音ズレ補正（±300ms）」で解決できます！ 「🎵BGM・録音」内のスライダーで歌声または内蔵BGMを1ms単位で遅らせてピタッと同期できます。
Q4. 配信中にOBSや歌詞画面を触りながら咳ミュートやMC切替はできますか？はい！ 「📌ミニバー」で画面の隅に小さく常駐させるか、裏画面ホットキー（Ctrl+Shift+M 咳ミュート／F9 長押し咳ミュート／Ctrl+Shift+T 歌枠⇄MC切替）で裏画面のまま操作できます（全角かな入力中でも誤爆しません）。
