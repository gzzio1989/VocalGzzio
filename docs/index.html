🎤歌枠⇄雑談MC ＆ 🔄5秒試聴ルーパー

曲間のトークでは「🎤歌枠/MC」1クリックで歌設定を保ったまま残響やハモリを一時オフ。「🔄5秒試聴」で5秒録音すれば、骨伝導のない客観的な自分の声をループ聴き比べながら両手で音作りできます。

クチュール5色 ＆ Argon 2D 重力場オーブ

♥LIVERモードには高級コスメ着想の5色（01ロゼ・02氷紫・03黒姫・04翡翠・05白桃）を搭載。母音へ倍音を加える「倍音」、輪郭を出す「声芯」、息づかいの「空気」、モノラル互換の「立体」を直感操作できます。

片耳マイク中央化 ＆ 配信出力ブリッジ

インターフェースの片側入力のマイクを自動で両耳中央へ揃える「🎯単音化」と、VB-CABLEやSYNCROOM等へ直接送る「📡外部出力」、歌っている最中の残響を自動回避する「IR・声優先ダッキング」を搭載しています。

使う前に知っておきたいこと

音程補正・ハモリは単独の歌声など、音程が１つの音源向けです。声とギターが混ざった入力を分離して補正する機能ではありません。音程処理には48kHzで約42.6ミリ秒の追加遅延があり、低遅延モードでは音程系を停止します。

内蔵の空間IRは計算生成した残響データです（実在の部屋の録音ではありません）。任意の `.wav` / `.aiff` IRファイルの読み込みにも対応しています。ノイズ除去や補正の適量は音源によって変わります。まず体験版で、ご自身の声や機材との相性をお確かめください。
