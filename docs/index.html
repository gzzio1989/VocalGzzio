🎵伴奏再生＆キー変更 ＆ ⏪直前30秒録音

伴奏音源（WAV/MP3/FLAC等）のキー（±6半音）を変えると歌声のピッチ補正・ハモリも自動同期。録音ボタンを押していなくても「⏪直前30秒を保存」で完成音（Wet）とMIX用素の声（Dry）を同時保存できます。

🎯5秒AI声質診断 ＆ 🛡絶叫・😷咳ガード
