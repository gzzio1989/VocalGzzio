.component はLogic Proなどが読み込む部品です。Finderで直接起動するアプリではありません。導入には .pkg、単体で使うときは導入済みの .app を開きます。

Mac版4.4.0の起動警告に対応中です。

現在の配布物はAppleの開発元証明書による署名・公証を受けていません。Macの保護機能によって導入や読み込みが拒否される場合があります。下の手順で開く対象を直しても、警告が解消するとは限りません。

Mac実機での導入・マイク入力・Logic Proでの試奏も未確認です。Macでの利用を目的に購入する前に、無料体験版で導入から音声処理までお確かめください。購入済みの方は、同じ購入履歴からWindows版・Mac版の両方を追加料金なしで取得できます。

ファイルの違い導入する警告が出たらLogic Proで使う問い合わせる

まず、この３つを見分けます。

.pkg

Macに導入する

プラグインと単体アプリを、使う場所へ配置するインストーラーです。

4.4.0では、名前が「未公証.pkg」で終わるファイルを使います。

.app

単体で起動する

録音ソフトを使わずにVocalGzzioを開くアプリです。

導入後、「アプリケーション」にあるVocalGzzioを開きます。

.component

Logic Proなどで使う

AU形式のプラグインです。導入後、録音ソフトの中で選んで読み込みます。

このファイル自体をダブルクリックして起動しません。

.vst3 も録音ソフト用のプラグインです。VST3に対応したソフトの中で選びます。Logic ProではAU形式を使ってください。体験版の名前には「Trial」が付きます。

インストーラーで導入する

  1. 公式の配布物を用意するBOOTHの商品ページの無料体験版、または購入履歴からMac版をダウンロードし、ZIPを展開します。対応するのはmacOS 11以降のAppleシリコン・Intel搭載Macです。
  2. 録音ソフトとVocalGzzioを終了する作業中の録音や設定を保存してから終了します。
  3. 「未公証.pkg」を開く内容を確認して導入します。管理者の認証が必要です。開発元確認の警告が出た場合は、次の「警告が出たら」を参照してください。
  4. 使う場所から開く単体なら「アプリケーション」のVocalGzzio、Logic Proなら録音ソフト内のAUプラグインから開きます。単体アプリでは、マイクの使用許可と入出力機器も確認します。
配置先を確認する・手動で導入する

インストーラーはAUを /Library/Audio/Plug-Ins/Components/、VST3を /Library/Audio/Plug-Ins/VST3/、単体アプリを /Applications/ に配置します。

自分の利用者アカウントだけに手動で入れる場合は、「手動インストール」フォルダーから次の場所へコピーします。.component・.vst3・.app は、中身を取り出さず丸ごとコピーしてください。

AUの配置先~/Library/Audio/Plug-Ins/Components/VST3の配置先~/Library/Audio/Plug-Ins/VST3/単体アプリの配置先~/Applications/

~ は自分のホームフォルダーです。Finderの「移動」→「フォルダへ移動」で配置先を入力できます。フォルダーがない場合は作成します。インストーラーと手動導入のどちらか一方で十分です。同じ製品版を両方の場所へ重複して入れないでください。

手動導入でも、開発元確認の警告が出る場合があります。

「検証できません」と表示されたら

「マルウェアが含まれていないことを検証できません」という警告は、Appleによる確認が取れないことを示します。この画面だけでマルウェアが検出されたとは判断できませんが、安全性の確認が済んだことを示すものでもありません。詳しくはAppleの警告についての説明をご覧ください。

  1. まず「完了」で閉じる.component を直接開いていた場合は、上の導入手順に戻り、録音ソフトの中から読み込みます。
  2. 入手元を確かめる公式BOOTHの商品ページ・購入履歴から取得したファイルか確認します。入手元や改変の有無に確信がない場合は開かず、お問い合わせください。
  3. 対象の許可を、ご自身で判断する内容を確認し、開くと判断した場合に限り、下のAppleが案内する操作を検討してください。利用を続けず、正式な署名・公証への対応を待つこともできます。
確認したファイルだけ「このまま開く」を選ぶ場合

必ず解決する手順ではありません。対象の許可ボタンが表示されない場合もあります。

  1. 導入時は .pkg、単体起動時は導入済みの .app を開いた際の警告を確認します。AUは導入してから録音ソフトで読み込みます。許可のために .component を直接開く操作は行いません。
  2. 「システム設定」→「プライバシーとセキュリティ」を開きます。古いmacOSでは「システム環境設定」→「セキュリティとプライバシー」です。
  3. VocalGzzioの該当ファイル名を確認し、その対象の「このまま開く」が表示される場合だけ選びます。確認画面でも、開く意思がある場合に「開く」を選びます。
  4. プラグインの場合は録音ソフトを再起動し、必要に応じてVocalGzzioだけを再スキャンします。

画面や操作の詳細はAppleの案内をご確認ください。管理されたMacでは設定を変更できない場合があります。

異なる警告が出たときは、操作を止めてください。
「破損している」「コンピュータに損害を与える」などの表示は、上の「検証できません」と異なります。警告を回避せず使用を中止してください。「このまま開く」がない場合や許可後も読み込めない場合も、繰り返し操作せずお問い合わせください。

Logic Proに表示されないとき

  1. .component が上記の配置先に丸ごと入っているか確認します。
  2. 作業を保存してLogic Proを終了し、Macを再起動します。
  3. Logic Proの「設定」（旧版は「環境設定」）→「プラグインマネージャ」でVocalGzzioを探します。
  4. 表示されていて検証に失敗している場合は、VocalGzzioだけを選び「選択項目をリセットして再スキャン」を実行します。

開発元確認の警告が残っている場合、再スキャンだけでは解決しないことがあります。対象が見つからない場合や再び失敗する場合は、他のプラグインの設定を変更せず、お問い合わせください。AppleのLogic Pro向け手順も参照できます。

うまくいかないときは

分かる範囲で次の情報を添え、BOOTHの商品ページからショップへお問い合わせください。

  • Macの機種とmacOSの版番号
  • 録音ソフトの名前・版番号、または単体アプリでの利用か
  • VocalGzzioの版番号と、製品版・体験版のどちらか
  • 警告の画像と、警告が出たときの操作
  • インストーラーと手動導入のどちらを使ったか

体験版は60秒ごとに0.6秒間音量が下がり、設定・プリセットの保存と復元が制限されます。製品版とは別の名前で導入されます。版番号は同梱の「配布情報.json」でも確認できます。
