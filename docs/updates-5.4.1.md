# VocalGzzio 5.4.1 変更記録（2026年10月30日）

**VocalGzzio 5.4.1（Vocal Expression & Custom SE Studio Edition — Clean-PC & Studio Stability Update）** では、`v5.4.0` で導入した4大ボーカル歌唱表現エンジン（**〰️ 語尾ビブラート**・**🗣️ 母音フォーム統一**・**⚡ 歌い出しグルーヴ**・**🌉 ミックス＆胸鳴り**）および **🎵 自作カスタムSE 4枠** に加え、クリーンなWindows環境での導入安定性・初回起動体験・DAWホスト互換性・長時間WASAPI配信の安定性を大幅に強化しました。

---

## 1. 🖥️ クリーンなWindows PCでの追加ランタイムDLL完全不要化 ＆ インストーラー導線改善

- Visual C++ 再頒布可能パッケージ（`vcruntime140.dll` / `msvcp140.dll` 等）が未導入の新品・クリーンなWindows 10 / 11 PCでも、DLL不足エラーを一切起こさずそのまま単体起動アプリ・VST3プラグイン・仮想ドライバインストーラーが起動できるようMSVC静的ランタイム（`/MT`）統合を行いました。
- 配布ZIP（体験版・製品版とも）のルート階層にオールインワンインストーラー（`VocalGzzio_Setup_v5.4.1.exe` / `VocalGzzio_Trial_Setup_v5.4.1.exe`）とMicrosoft WHQL署名済み `VocalGzzio Driver (WDM)` を確実同梱し、インストール完了画面からそのまま「今すぐ単体起動アプリを起動する」チェックボックスとデスクトップショートカットを標準利用できるようにしました。
- ARM64 Windows環境でのWDMドライバ導入時の安全スキップ判定と、既存の重複WDM仮想ノードの自動整理に対応しました。

---

## 2. 🎤 初回起動時のマイク自動開通・1クリックミュート解除バナー ＆ アプリ内説明書ボタン

- 初回起動時の自動マイクミュート解除およびワンクリック解除バナーを搭載し、`ASIO4ALL` 等の排他ラッパーを誤って掴んで他アプリ（ブラウザ・OBS・VRChat・Discord等）の音が消えてしまうトラブルを未然に回避するよう改善しました。
- アプリ画面内からワンクリックで取扱説明書を開ける導線を追加しました。

---

## 3. 🎛️ DAWプロジェクト保存データと単体起動版（Standalone）設定の完全分離 ＆ `1ch → 2ch` 対応

- Cubase / Studio One / REAPER / FL Studio / Ableton Live 等のDAW上でVST3/AUプラグインとして挿した際、DAWプロジェクト側の保存ステートと単体起動アプリ（Standalone）側の常駐設定ファイルが互いに干渉・上書きしないよう完全に分離しました。
- **DAWモノラル入力 → ステレオ出力（`1ch → 2ch`）正式対応**：ボーカル用のモノラルトラックにそのまま挿して、空間IRリバーブや5人ユニゾン・ステレオワイドの広がりを左右ステレオで出力できます。

---

## 4. 🎵 MP3デコード標準有効化・セットリスト32曲統一 ＆ カスタムSEサンプルレート自動追従

- Windows / macOS 全環境で `.mp3` 伴奏・カスタムSE音源のネイティブデコードを標準有効化しました。
- 歌枠セットリストの上限を全画面で最大32曲に統一し、オーディオデバイスのサンプルレート（44.1kHz / 48kHz / 96kHz等）を切り替えた際も登録済みカスタムSE 4枠が自動でリサンプリング追従するよう改善しました。

---

## 5. ⏱️ 長時間（5時間超）WASAPI共有モード配信のクロックドリフト解消 ＆ 音量ミキサー重複解消

- USBマイク入力と別DAC／ヘッドホン出力を組み合わせたWindows WASAPI共有モードでの長時間歌枠配信において、`±2〜5 ppm` の水晶クロック差が約3.9時間後にリングバッファの上限／下限へ達してプチプチ音（クラックル）を起こす問題を解消しました。
- Windowsの「音量ミキサー」に同一アプリのスライダーが重複して増える現象（未初期化セッションGUID起因）を修正しました。
