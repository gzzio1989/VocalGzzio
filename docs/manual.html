はじめの調整

  1. 単体起動では上部の「⚙音声機器と入出力の設定」またはワンクリックボタン（「🌐全アプリ共存・共有モード」「🛠cluster・通話 音消え一発修復」）でマイクと出力を選びます。プラグインでは録音ソフトの音声トラックへ挿します。
  2. 入力チャンネルは既定の「Auto Mono IN1-4」にしておくと、入力1（左ch）・入力2（Scarlett Solo等の右ch）・入力3〜4（Rubix44等の4ch機）のどこにマイクを挿しても自動で声のチャンネルを追尾して両耳中央（L+R）へ揃えます（MOTU M2/M4等のIN 3-4ステレオループバックは自動で除外します）。

  4. 「押して原音と比較」や「🔄5秒試聴ルーパー」で、処理前後の声を客観的に聴き比べます。

カラオケ伴奏・30秒さかのぼり録音・5秒AI声質診断

  • 🎵内蔵カラオケ・BGMプレイヤー ＆ キー変更（±6半音）：上部の「🎵BGM・録音」から手持ちの伴奏音源（.wav / .mp3 / .flac / .ogg / .aiff）や内蔵J-POPカノン進行伴奏を再生できます。伴奏キー（-6〜+6半音）を変更すると、ボーカル側のピッチ補正・ハモリのキーも自動同期します。歌唱中は「声優先オートダッキング」で伴奏が自動で少し下がります。
  • 🔴1クリックWAV録音 ＆ ⏪直前30秒さかのぼり保存：通常の24bit WAV録音に加え、録音していなかった時でも「⏪直前30秒を保存」を押すだけで直前30秒間の歌声を救出できます。常に「完成音（Wet）」と「無加工の素の声（Dry）」の2ファイルが同時保存されます。
  • 🎯5秒AI声質ターゲット診断：5秒間歌うだけで声の重心・明るさ・倍音バランスを計測し、選んだ理想スタイル（✨透明感ウィスパー／🎤王道アイドル／🔥パワフルロック／🌙深みイケボ／🎧耳元ASMR）に合わせて2D声質オーブとEQを自動調律します。
  • 🛡絶叫セーフティガード ＆ 😷咳払い8ms瞬間ミュート：突発的な大声を0.2msアタックで-0.3dBFS以内に抑える絶叫ガードと、ポップノイズ皆無（8msクロスフェード）で即座に無音化する咳ミュートを搭載しています。

対応オーディオインターフェース一覧 ＆ cluster・通話の音消え対策

サウンドハウス・Amazonで販売されている主要60ブランド・160機種以上（44.1kHz〜192kHz / 16bit〜32bit Float / 1ch〜16ch）に対応しています。

  • 🛠cluster・通話 音消え一発修復：Windowsの「通信時の80%音量低下（ダッキング）」を自動無効化し、入出力サンプルレートを48kHzへ統一してオーディオパイプラインを即座に再起動します。
  • 🌐全アプリ共存・共有モード（USBマイク/VR/排他ASIO用）：ASIO4ALLや排他ASIOドライバが他のアプリ（cluster / VRChat / Discord / ゲーム / ブラウザ）の音を止めてしまう場合や、USBマイク・Meta Quest 3等をお使いの場合にクリックすると、全アプリと音が共存できる低遅延共有モード（WASAPI）へ1クリックで切り替わります。
  • 🎧自分の耳への返しミュート：配信先・通話先（「ライン (VocalGzzio Driver (WDM))」）へはエフェクト後の声を送り続けながら、自分のヘッドホンへの返しだけを消して二重聞こえやハウリングを防ぎます。
  • 本体LOOPBACK切り忘れ・ハウリング緊急遮断ガード：YAMAHA AG03/AG06やSteinberg UR22C、Roland Rubix等の本体LOOPBACKがONのままモニターを返して発振しそうになった場合、0.35秒で自動検知して耳への返しだけを安全ミュートします（配信出力は止まりません）。
  • 32-bit Float 自動ヘッドルーム正規化：ZOOM UAC-232/432やSteinberg URX22C等で0dBFS（|x|>1.0）を超える32bit Float入力が入っても、先頭で歪みなく自動減衰して音割れを防ぎます。

声の質感を調整する（2Dオーブ）

項目変化と使いどころ
倍音（VELVET）声に温かみや厚みを加えます。強くかけてざらつきを感じたら下げます。
声芯（FOCUS）中高域を足して言葉の輪郭を出します。伴奏に埋もれるときに少量から使います。
空気（SILK）高域の息づかいや明るさを加えます。サ行や背景ノイズも目立つ場合は下げます。
立体（HALO）声の周囲にステレオの広がりを加えます。モノラルでも位相が濁らない設計です。

音量そろえ・絶叫セーフティガード・咳ミュート

声を出している間に計器盤の音量補助ボタンを押すと、その時点の出力ピークから出力音量を補正します。突発的な叫び声やマイク衝突音は「🛡絶叫ガード」が0.2msで抑え込み、咳払いは「😷咳ミュート」でクリックノイズなく遮断できます。

ノイズを減らす

声や楽器を出さずに「ノイズを測る」を押し、除去量を20〜40％から少しずつ上げて聴き比べます。声を誤って学習した場合は「学習を消す」でリセットできます。

音程補正・5人ハモリと楽器のチューナー

曲のキーと音階を合わせ、補正量と速さを調整します（内蔵カラオケ伴奏のキー変更とも自動連動します）。音程処理を使うと48kHzで約42.6ミリ秒の追加遅延が生じます。低遅延モードでは音程系を停止し追加遅延0.0ミリ秒で動作します。

リバーブと空間IR（カスタムIR読込対応）

6種類の空間IR（おふろ・カラオケ箱・録音スタジオ・ライブハウス・コンサートホール・プレート）に加え、「📂IR読込」からお手持ちの .wav / .aiff IRファイルを読み込めます。「声優先ダッキング」を入れると歌っている最中だけ残響が自動で少し下がり、歌詞がくっきり聞こえます。

インストールと更新

録音ソフトと単体起動アプリを終了してから、配布物のインストーラーを実行します。WindowsではVST3・単体起動アプリ・専用仮想ドライバ「VocalGzzio Driver (WDM)」が導入されます（元の既定スピーカー・マイクは自動で保護・復元されます）。Macは同梱の「ここから始める.html」に沿って .pkg を実行します。
