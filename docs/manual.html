ひとつずつ決める。

まずは総合画面で「仕上がり」を選び、必要なところだけ調整します。中央のオーブと4本のバーで声の質感を変えられます。

はじめの調整

  1. 単体起動では音声機器と入力を選びます。プラグインでは、録音ソフトの音声トラックへ挿します。
  2. 「うた」「アコギだけ」「しゃべり」「声とギター」から入力に合うものを選びます。ギターの音と声が1本のマイクに入る場合は「声とギター」です。
  3. いちばん強く歌う・弾くところで入力が歪まないよう、音声機器の入力ゲインを調整します。録音時点の歪みは後から元に戻せません。
  4. 「仕上がり」から目的に近いものを選ぶか、「声に合わせる」の自動調整を使います。音色を試すために仕上がりを選んでも、ノイズを勝手に再学習しません。
  5. 「押して原音と比較」を押したまま、処理前の音を聴きます。離すと設定した音に戻ります。大きい方を良い音と感じやすいので、音量を近づけて、輪郭・強弱・余韻を聴き比べます。

声の質感を調整する

総合画面の中央にある丸い操作点「オーブ」をドラッグすると、4つの音色項目をまとめて調整できます。4本のバーでは1項目ずつ調整します。オーブを動かしても、ほかの音色つまみや残響量は変わりません。

項目変化と使いどころ
倍音（VELVET）声に温かみや厚みを加えます。強くかけてざらつきを感じたら下げます。単独の声向けです。
声芯（FOCUS）中高域を足して言葉の輪郭を出します。伴奏に埋もれるときに少量から使います。声が硬く聞こえるときは下げます。単独の声向けです。
空気（SILK）高域の息づかいや明るさを加えます。サ行や背景ノイズも目立つ場合は下げます。
立体（HALO）声の周囲にステレオの広がりを加えます。左右のある出力で確認し、モノラルでも聞こえ方を確かめます。

バーをダブルクリックするとその項目だけ0％へ、オーブをダブルクリックすると4項目が0％へ戻ります。「歌枠」「ASMR」「ポップス」「バラード」のボタンは、音づくりの出発点として使えます。「声に合わせる」の自動調整も、分析した帯域バランスから4項目の初期値を提案します。好みや伴奏に合わせて最後に聴いて調整してください。

5つのペルソナ配置・クチュール5色・軽量表示

画面上部から配置と世界観を選べます。「★ARGON」は中央の音色調整を大きく見せる近未来ガラス調、「♥LIVER」は配信・歌枠向けのクチュール・コスメ調、「☕ゆるふわ」は目に優しいカフェ調（再クリックで昼・夜切替）、「🎛STUDIO」は録音機器のように縦列へ並べる木目＆真鍮コンソール調、「◎従来」は3つのカードに分かれた配置です。配置を変えても同じ音声設定を使います。

クチュール・コスメティック5色パレット：「♥LIVER」を選ぶと、画面上部に 01ロゼ・02氷紫・03黒姫・04翡翠・05白桃 の5色スウォッチが現れ、1クリックでカラーバリエーションを切り替えられます（「文字・見た目」からも選択できます）。

「⚡軽量」を入れると、画面の更新や装飾を減らします。音声処理の設定は変わりません。画面が重いと感じる場合や、配信と録音を同時に行う場合に使ってください。

単体起動版：片耳マイク中央化と外部配信出力ブリッジ

  • 🎯声モノラル中央（片耳マイク対策）：オーディオインターフェースの入力1（左チャンネル）だけにマイクを挿したとき、左耳からしか声が聞こえない状態を防ぎ、自動で中央（両耳）へ揃えます（単体起動版では既定でON）。ステレオ入力をそのまま通したいときはクリックしてOFFにします。
  • 📡配信出力（SYNCROOM / OBS / VRChat ブリッジ）：単体起動版で整えた声を、ヘッドホンでモニターしながら別の仮想オーディオ出力（VB-CABLE、Yamaha SYNCROOM / NETDUETTO 等）へ直接送出できます。

出力音量を合わせる

声を出している間に計器盤の音量補助ボタンを押すと、その時点の出力ピークから出力音量を補正します。音が入っていないときは設定を変えません。大きすぎる音では出力音量を下げる方向に調整します。下げても足りない場合は、表示の案内に従って入力音量を下げてください。

補助ボタンは、その後の大声まで自動で追い続ける機能ではありません。いちばん強く歌う箇所でも確認してください。内部の目安である−14 dBFSは瞬間的なピークの基準で、配信サービスで用いられる−14 LUFSへの自動調整ではありません。

音量保護は大きな音で音量を緩やかに下げる補助です。瞬間的なピークをすべて止めるわけではありません。録音ソフトの後段で音量を上げた場合や、マイク・音声機器ですでに歪んだ入力には対処できません。

ノイズを減らす

  1. マイクを普段の位置に置き、声や楽器を出さずに「ノイズを測る」を押します。
  2. 測定が終わったらノイズ除去が入っていることを確認し、除去量を20〜40％から少しずつ上げて聴き比べます。測定ボタンを押しても除去量は変わりません。0％や処理切では音は変わりません。
  3. 語尾や息が欠ける、声が薄いと感じたら下げます。ノイズと声が同じ帯域にある場合、完全に分けることはできません。

無音時のカットは、小さい入力を閉じるゲートです。歌っている間のノイズを抑えるノイズ除去とは役割が異なります。使わないときは各入／切ボタンで比較します。声をノイズとして学習した場合は、総合画面の「学習を消す」から消してやり直します。

音程補正と楽器のチューナー

音程補正とハモリは「音程・ハモリ」から設定します。曲のキーと音階を合わせ、補正量と速さを調整します。無声子音や息を無理に音程へ引き寄せない処理ですが、声質・奏法によって不自然さが残ることがあります。

音程処理を使うと48kHzで約42.6ミリ秒の追加遅延が生じます。現在の値は画面上部に表示します。低遅延モードは音程系を停止します。音声機器や録音ソフトの遅延は別に発生します。声とギターが混ざった音源の分離補正には対応していません。

「チューナー」で大きな音程表示を開けます。「ギター調弦」を選び、開放弦を1本ずつ鳴らします。標準調弦は6弦から E2・A2・D3・G3・B3・E4。大きくずれている場合は弦を指定し、表示が中央に来るように合わせます。基準は通常440Hzです。

4弦ベースは E1・A1・D2・G2、5弦ベースは B0・E1・A1・D2・G2 に対応します。楽器を選び、ほかの弦を止めて1本ずつ鳴らしてください。針が落ち着くと「安定」、中央に合うと「ぴったり」と表示します。楽器と指定弦は開き直しても引き継ぎます。

リバーブと空間IR（カスタムIR読込対応）

リバーブの入／切は独立したボタンです。残響の量は原音に加える響き、残響の長さは余韻を調整します。速い曲では短めにすると次の言葉を邪魔しにくくなります。

通常のリバーブに加えて、6種類の空間IR（おふろ・カラオケ箱・録音スタジオ・ライブハウス・コンサートホール・プレート）を選べます。内蔵の空間IRは計算生成した残響データを畳み込む方式で、実在の部屋を録音したものではありません。さらに「📂IR読込」ボタンから、お手持ちのインパルス応答ファイル（.wav / .aiff）を読み込んで使用することもできます。カード内の波形表示で残響の減衰カーブを確認できます。

表示・保存・比較

「文字・見た目」で文字サイズ、画面サイズ、各ペルソナテーマ・クチュール5色、軽量モードを変えられます。ブランドテーマは英語です。総合画面を既定とし、詳細画面からいつでも戻れます。製品版ではAとBに異なる設定を保存して切り替え、「保存」「読込」で設定ファイルも扱えます。保存済みの製品版プロジェクトを開いても、新しい仕上がりを自動適用しません。

体験版は60秒ごとに0.6秒だけ音量が下がります。A/B比較・設定の保存・読込は使えず、次回起動や録音ソフトのプロジェクト再読込では音声設定が初期状態になります。「押して原音と比較」は体験版でも使えます。

インストールと更新

録音ソフトと単体起動アプリを終了してから、配布物のインストーラーを実行します。WindowsではVST3と単体起動を選べます。導入後に録音ソフトのプラグイン一覧を再読み込みしてください。製品版と体験版は名前が異なります。

MacはZIPを展開し、同梱の「ここから始める.html」の案内に沿って .pkg を実行します。単体起動版は「アプリケーション」へ導入されます。録音ソフト用の .component／.vst3 は部品なので、直接起動しないでください。Macの導入と起動警告についての案内も用意しています。Appleの開発者署名・公証の有無と確認済み環境は、同梱の配布情報と商品ページでご確認ください。音声機器のドライバーとマイクの使用許可も必要です。

更新では音質修正による音の違いが生じます。大事な録音では、更新前のプロジェクトと音を書き出して保管してください。

音が変わらないとき

  • 処理区画・個別機能が「切」になっていないか確認します。
  • 低遅延モード中は音程系が停止します。
  • 詳細画面の原音／処理音の混合が原音だけになっていないか確認します。
  • ノイズ除去やサ行おさえなどは、対象の成分がない音では変化が小さくなります。
  • 処理後の音を聴いているか、音声機器の直接モニターと二重になっていないか確認します。単体アプリを終了しても同じマイク音が聞こえる場合は、音声機器側のモニター経路も確認します。
