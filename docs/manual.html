はじめの調整

  1. 単体起動では上部の「⚙音声機器と入出力の設定」またはワンクリックボタン（「🌐全アプリ共存・共有モード」「🛠cluster・通話 音消え一発修復」）でマイクと出力を選びます。OBS Studio や DAW のプラグインとして使う場合は音声トラック／フィルタへ直接挿します。
  2. 入力チャンネルは既定の「Auto Mono IN1-4」にしておくと、入力1（左ch）・入力2（Scarlett Solo等の右ch）・入力3〜4（Rubix44等の4ch機）のどこにマイクを挿しても自動で声のチャンネルを追尾して両耳中央（L+R）へ揃えます（MOTU M2/M4等のIN 3-4ステレオループバックは自動で除外します）。

  4. 「押して原音と比較」や「🔄5秒試聴ルーパー」で処理前後の声を聴き比べ、配信本番中はヘッダーの「📌ミニバー」を押してコンパクト常駐バーへ切り替えられます。

声の質感を調整する（2Dオーブ）

項目変化と使いどころ
倍音（VELVET）声に温かみや厚みを加えます。強くかけてざらつきを感じたら下げます。
声芯（FOCUS）中高域を足して言葉の輪郭を出します。伴奏に埋もれるときに少量から使います。
空気（SILK）高域の息づかいや明るさを加えます。サ行や背景ノイズも目立つ場合は下げます。
立体（HALO）声の周囲にステレオの広がりを加えます。モノラルでも位相が濁らない設計です。

音量そろえ・絶叫セーフティガード・咳ミュート

声を出している間に計器盤の音量補助ボタンを押すと、その時点の出力ピークから出力音量を補正します。突発的な叫び声やマイク衝突音は「🛡絶叫ガード」が0.2msで抑え込み、咳払いは「😷咳ミュート」（または裏ホットキー Ctrl+Shift+M / F9 長押し）でクリックノイズなく遮断できます。

ノイズを減らす

声や楽器を出さずに「ノイズを測る」を押し、除去量を20〜40％から少しずつ上げて聴き比べます。声を誤って学習した場合は「学習を消す」でリセットできます。

音程補正・5人ハモリと楽器のチューナー

曲のキーと音階を合わせ、補正量と速さを調整します（内蔵カラオケ伴奏のキー変更とも自動連動します）。ピッチ補正単独では約0.08ms〜2.9msの時間領域エンジンが働き、ボイス変換併用時は選択した遅延モードに応じた窓長で動作します。またギター／ベース多弦チューナーを開いている間のみ長窓YIN解析が動き、通常のうたモードでは音声スレッドとロックフリーF0共有するためUI負荷ゼロで常時ピッチ表示されます。

リバーブと空間IR（カスタムIR読込対応）

6種類の空間IR（おふろ・カラオケ箱・録音スタジオ・ライブハウス・コンサートホール・プレート）に加え、「📂IR読込」からお手持ちの .wav / .aiff IRファイルを読み込めます。「声優先ダッキング」を入れると歌っている最中だけ残響が自動で少し下がり、歌詞がくっきり聞こえます。
