# 4.3.1の修正内容

4.2.1のノイズ除去と画面操作の報告を受けた修正版です。4.3.0で準備した修正も本版に含みます。配布開始と対応環境は[BOOTHの商品ページ](https://gzzio.booth.pm/items/8764003)で案内します。

## ノイズ除去

- 起動直後にノイズ除去を上げても定常ノイズが長時間そのまま通る条件を修正しました。
- 大きめのノイズという理由だけで測定を拒否せず、音の周期性と変動から判定します。
- 小さい持続声やギターの和音をノイズとして学習し、演奏の音量を下げる条件を修正しました。
- 新方式で測定したノイズ情報を保存・再起動後も復元します。不正な保存値は除外します。
- 総合画面に測定中・学習済・除去量0％・処理切を区別して表示します。「ノイズを測る」は除去量を変更しません。
- **ノイズ除去がまったく効かなくなる条件を修正しました（4.3.1）。** 入力が来ていない状態（機器のミュート、入力端子の選び間違い、ケーブル未接続）で「ノイズを測る」を押すと、存在しないほど静かなノイズの大きさをそのまま覚えてしまい、以後ノイズ除去が一切働かなくなることがありました。覚えた内容は設定に保存されるため、単体起動版では再起動しても直りませんでした。測定時と設定の読み込み時の両方で、静かすぎる値を採用しないようにしました。入力が無いときは「測れませんでした」と表示し、前の設定を保持します。

## 画面操作

- 総合画面の更新でチューナーや設定の小窓を隠し、閉じた小窓を次の画面切替で参照し得る処理を修正しました。
- 「詳細調整」「音程・ハモリ」「チューナー」の操作と、小窓を閉じてからの再操作を検査に追加しました。
- 画面切替ボタンを押した瞬間に設定ファイルの書き込みを待たせないようにしました。
- 異なる画面表示を使う複数のプラグインで、日本語／ブランド英語が互いに影響する処理を分離しました。

## チューナー

- 針の瞬間的な跳ねを抑え、約0.2秒の時定数で動きをなめらかにしました。表示の平滑化による音声の遅延はありません。
- 音程が落ち着いた状態と、中央に合った状態を区別します。音が消えた後の残像を調弦完了にはしません。
- 標準6弦ギターに加え、4弦ベース（E1・A1・D2・G2）と5弦ベース（B0・E1・A1・D2・G2）に対応しました。開放弦を1本ずつ鳴らしてください。
- 楽器と指定弦の選択を、拡大表示・開き直し・保存した状態の復元で引き継ぎます。
- 片側入力や左右が逆相の入力でも、チューナー用の音が小さくなったり消えたりしないようにしました。出力の音には手を加えません。
- 非表示中のチューナー解析を止めました。

## チューナー（4.3.1で追加）

- 片方の入力だけに楽器をつないでいるとき、直前に大きい音が入っていると解析する側の切り替えに約0.3秒かかり、その間の音程表示がずれる問題を修正しました。96kHz・192kHzで誤差が大きく出ます（右だけに5弦ベースの最低音を入れた状態で約9.8セント）。修正後は0.09セントです。
- 切り替えは「見ている側が完全な無音のとき」だけ即座に行います。小さい楽器の音で表示がばたつくことはありません。

## 検証と配布

Windowsで50件の自動検査に合格しました。本体に合成音を入力して、ノイズ、声、和音、低いベース音、入力チャンネル、保存復元、処理時間を検査します。ノイズ除去は、ノイズの門を入れた出荷状態のまま、サンプルレート44.1k〜192kHz・バッファ32〜256・モノとステレオ・片側入力の12通りで効きを確認しています。画面は実際の操作イベントを通し、音声処理中の切替も確認します。報告者の実機での再確認は別途必要です。

Mac版では、最適化時に製品版／体験版の識別情報が消えて梱包に失敗する条件も修正しています。Macでの検査・梱包完了前に配布済とは案内しません。
