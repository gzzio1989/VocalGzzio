# VocalGzzio 4.8.0 の変更点（Stage & Studio Complete Edition）

公開日：2026年10月19日

## 1. サウンドハウス・Amazon主要60ブランド・160機種以上の全インターフェース・USBマイク・VR機器への完全対応
- **44.1kHz〜192kHz / 16bit〜32bit Float / 1ch〜16chマルチチャンネル**のあらゆるオーディオインターフェース・配信ミキサー・USBマイク・ゲーミングDAC・VRヘッドセット（Meta Quest 3 / Valve Index / HTC VIVE / PICO 4）に対応しました。
- **「🛠cluster・通話 音消え一発修復」「🌐全アプリ共存・共有モード（USBマイク/VR/排他ASIO用）」「🎧自分の耳への返しミュート」** の3つのワンクリックボタンを単体起動アプリ上部に搭載し、`cluster`・`VRChat`・`Discord`・`OBS`・ゲームと同時に起動しても音が消えない設計にしました。
- **IN 1〜IN 4 自動追尾（Auto Mono IN1-4）**：Focusrite Scarlett Solo（第3・第4世代）の右ch（`IN 2`）マイクや Roland Rubix44 / Steinberg UR44C 等の4ch入力を自動検出し、MOTU M2/M4 や Audient EVO 4/8 の `IN 3-4` ステレオPCループバックを自動除外して中央（L+R）へ揃えます。
- **32-bit Float 自動ヘッドルーム正規化**：ZOOM UAC-232 / UAC-432 や Steinberg URX22C / URX44C、TASCAM FR-AV2 等で `0 dBFS`（`|x| > 1.0f`）を超える浮動小数点入力が入っても、先頭で歪みなく自動減衰します。
- **本体 LOOPBACK 切り忘れ・ハウリング緊急遮断ガード**：YAMAHA AG03MK2 / AG06MK2 や Steinberg UR22C 等の本体 `LOOPBACK` がONのままモニターを返して発振しそうになった際、0.35秒で検知して耳への返しだけを安全ミュートします（配信出力は継続）。
- **USB瞬断・スリープからの2秒自動ホットプラグ復帰**を搭載しました。

## 2. 内蔵カラオケ・BGMプレイヤー ＆ キー変更（±6半音）＆ 声優先オートダッキング
- 手持ちの伴奏音源（`.wav / .mp3 / .flac / .ogg / .aiff`）および内蔵デモ伴奏の再生に対応しました。
- 伴奏のキー（`-6〜+6半音`）を変更すると、ボーカル側のピッチ補正・ハモリのキーも自動同期します。

## 3. 1クリックWAV録音 ＆ 直前30秒さかのぼり保存（Wet完成音＋Dry素の声 同時保存）
- 録音ボタンを押していなくても「⏪直前30秒を保存」を押すだけで、直前30秒間の歌声を24bit WAVで救出できます。
- 常に「エフェクト込みの完成音（Wet）」と「MIX提出用の素の声（Dry）」の2ファイルがペアで保存されます。

## 4. 5秒AI声質ターゲット診断 ＆ 絶叫セーフティガード ＆ 咳払い8ms瞬間ミュート
- 5秒歌うだけで5つの理想ターゲット（透明感ウィスパー／王道アイドル／パワフルロック／深みイケボ／耳元ASMR）へ2DオーブとEQを自動調律します。
- 0.2msアタックの「🛡絶叫セーフティガード（-0.3dBFS保護）」と、クリックノイズ皆無（8msハニング窓クロスフェード）の「😷咳ミュート」を搭載しました。
