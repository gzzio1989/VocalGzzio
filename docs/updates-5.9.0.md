# VocalGzzio 5.9.0 変更記録（2026年11月15日）

**VocalGzzio 5.9.0（Zero-Latency Singing-Skill Suite & Broken-Mic Safu/Crackle ANC Edition）** では、**「挿した瞬間に歌が上手く聴こえる」** ためのゼロ遅延ボーカル表現＆音程微揺れ制振エンジン **『歌うま補正（Vocal Intonation Stabilizer ＆ 歌唱表現6エンジン一括最適化）』** と **プロ仕様『歌うま初期レシピ』** の全面刷新、さらに経年劣化・大声入力・スポンジ風防共鳴で壊れかけたマイクから発生する **「サフサフ音・母音中のパリパリ／チリチリ音・スピーカー擦れ（Rub & Buzz）」をゼロ遅延で引き算する『劣化マイク・サフサフ／チリチリ除去（Chirp-Extrapolated 6-Band Orthogonal ANC）』** を新搭載しました。あわせて日本語「ふつう」画面（Obsidian-Slate Studio）での確実な初期起動、詳細画面のワンクリック「歌うま補正」「自然音程」ボタン、およびリバーブ種別コンボボックスの1対1精密同期修正を行っています。

## 1. 🎤 挿した瞬間に上手く聴こえる『歌うま補正（Zero-Latency Singing-Skill Suite）』＆ プロ初期レシピ刷新

- **① ゼロ遅延・音程微揺れスタビライザー（`VocalIntonationStabilizer` / 追加遅延 `0.0 ms`）**：
  - ロングトーン発声時に素人の声っぽさの原因となる **1.5〜3.5 Hz の不安定な音程のフラつき（±15〜25 セント）** を、ドップラー分数遅延（`1.95 ms` 整数中心タップ・3次エルミート補間）によって **最大 68.6% 自動制振** し、ピタッと芯の通ったプロの発声安定感へ整えます。
  - **しゃくり・こぶし・表現ビブラート完全保護**：`0.52` 半音を超えるメロディ移動やしゃくり・こぶしは瞬時に追従し、レイリー瞬時変調周波数分類器によって **4.1〜8.8 Hz の心地よい歌唱ビブラートは 94.9% そのまま温存** します。また無声子音（サ行・タ行・ブレス）は厳密整数遅延タップへ自動回帰し、**子音明瞭度 99.98%（位相劣化ゼロ）** を保ちます。
- **② オートピッチ OFF 時もゼロ遅延 F0 解析が全表現エンジンを常時駆動**：
  - ピッチ補正（`at_on`）を OFF にしている状態でも、ゼロ遅延ピッチ検出器の基本周波数（$f_0$）が **音程微揺れスタビライザー・音程追従スイートスポットEQ・ミックスボイス倍音ブリッジ・語尾ナチュラルビブラート** へリアルタイム供給されるよう内部結線を刷新しました（本人が自然なビブラートをかけている時は人工ビブラートが自動で一歩引く `natVibGuard` 付き）。
- **③ 挿した瞬間から完成された『歌うま初期レシピ』＆ 全プリセット連動**：
  - 初期状態および「初期化」ボタンのレシピをゼロから再設計しました：
    - **不要なこもり・濁りの整理**：ローカット `105 Hz`、こもり `-3.8 dB`、キンキン `-1.2 dB`、スマートEQ `ON`（自動EQ量 `38%` / 共鳴狙い `55%`）。
    - **歌声が前に出る2段コンプ＆音量ライド**：ピーク圧縮 `38%` ＋ ならし圧縮 `42%`（`12 ms / 115 ms`）＋ 音量キープ `35%` ＋ つぶさないガード `ON`。
    - **プロスタジオの艶と立体空間**：ヌケ感 `+3.4 dB`、キラキラ `+3.5 dB`、あたたかみ `18%`、のび `24%`、艶 `28%`、4軸オーブ（`Velvet 32% / Focus 46% / Silk 44% / Halo 22%`）、および **スタジオ・プレート残響（`プレート` / 広さ `42%` / ひびき `16%` / ダッキング `36%` / ひろがり `18%` / かさね `10%` / やまびこ `6%`）**。
  - 総合画面の **6大仕上がりプリセット**・**全20曲調ジャンルプリセット（空間＆歌うま設定連動）**・**3大シーン（弾き語り／バンド／トーク配信）** もすべてプロ品質レシピへ強化しました。
- **④ 詳細画面ヘッダーに『歌うま補正』『自然音程』『劣化修復』ワンクリックボタン新設 ＆ 表示改善**：
  - 詳細画面の右上ヘッダーからワンクリックで **`歌うま補正`**（歌唱表現6エンジン＋微揺れ制振）・**`自然音程`**（キー未設定時でも外れないクロマチック・ナチュラル補正 `62%`）・**`劣化修復`**（OFF ➔ 標準 ➔ 強力）を即座に切り替えられるようになりました。
  - シーン未選択時に「トーク配信」が誤点灯していた表示バグ、およびリバーブ種別コンボボックスの正規化スケーリングによる表示ズレ（`プレート` 設定時に `ルーム` と表示されていた問題）を完全に解消しました。

## 2. 🛡️ 壊れかけマイクの「サフサフ・パリパリ・チリチリ音」を消す『劣化マイク修復 ANC』＆ 長時間復活防止アンカー

- **Chirp-Extrapolated 6-Band Orthogonal ANC（追加遅延 `0.0 ms` / CPU 負荷 `3.75%`）**：
  - 通常のノイズキャンセリングをすり抜けて発声中に乗ってしまう3大マイク劣化ノイズを、声の倍音構造と直交分離してゼロ遅延で除去します：
    1. **「あー」発声中のパリパリ・チリチリ音（ダイアフラム湿気アーク放電・ADC微細スパイク）**：4周期チャープ整合トリム予測と広帯域（`185 Hz〜24 kHz`）同期クランプにより、連続高密度パリパリ音も参照リングを汚染せず外科修復（**+18.45 dB 低減**）。
    2. **スポンジ風防共鳴・自然減衰語尾のサフサフ／ボフボフ音**：周期コム予測残差から非調波の風防共鳴エネルギーだけを抽出し、自然な語尾減衰後のサフー残響も **+10.73 dB 抑制**。
    3. **壊れたスピーカーのようなサフー擦れ音（Rub & Buzz 高次非対称歪み）**：声の包絡線に追従する高域非調波バズ抑制（**+10.11 dB 低減**）と、1次IIRピッチ同期ハーモニックコム（倍音間ヒス **-9.08 dB 低減**）を統合し、子音明瞭度 **100.0%** を維持します。
  - **長時間配信での「サフサフ・パリパリ音復活」完全根絶（アンカー保持 ＆ 自動センチネル ＆ WASAPI 256サンプル平滑）**：
    - `じどう学習`（`dn_relearn`）ONのまま静穏な時間が続いても手動学習したノイズ床アンカーを決して忘却しない下限保護、歌枠途中でカプセル結露により突発発生したパリパリ放電を検知して自動で `劣化修復` を起動する無音時CPU 0%センチネル、およびUSBマイク長時間稼働時のWASAPI共有クロックドリフト境界補間（256サンプル長尺マイクロフェード）を統合しました。
  - 「うた自動」「トーク自動」実行時にもマイクの劣化兆候を自動診断し、すでに有効化されている `劣化修復` モードを下げることなく保護します（総合画面「01 整える」および詳細画面ヘッダーの `劣化修復` ボタンから手動切替も可能）。
