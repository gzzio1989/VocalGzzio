# VocalGzzio 6.0.0 — Carbon Edition 変更記録（2026年11月17日）

**VocalGzzio 6.0.0（Carbon Studio Monolith & Unified Vocal Engine Edition）** は、これまでの全世代（v1.0〜v5.9）で培ったボーカル音響知能を工業ハードウェア設計（Carbon）の視点から徹底的に再監査・再構築した **メジャーアップデート第6世代フラッグシップ** です。AI生成ツールっぽさの原因だったベタ塗りスイッチ・絵文字装飾・SF球体・詳細画面の空き領域を一掃して **プロ用スタジオ機材としての機能美（Carbon Monolith UI）** を確立するとともに、DSP信号経路の全段監査により **並列Mix時の位相打ち消し根絶・11.8kHz超高域シルク空気感保護ディエッサー・M/S残響ボーカルポケット・1次ADAA倍音・スペクトル予算調停・ITU-R BS.1770-4リアルタイムLUFS/dBTP結線** を達成しました。

## 1. 🎛️ 『Carbon Monolith』プロスタジオ・ハードウェアUI ＆ 操作動線の人間工学刷新

- **① フォージドカーボン筐体 ＆ 3系統セマンティック色秩序（WCAG AAA 16.1:1）**：
  - 青紫かぶりを排した純黒鉛フォージドカーボン下地（`#0D1015`〜`#080A0E`）と1pxチタンヘアラインを採用。
  - 信号系統を **Clean（Signal Emerald `#28C095`）／Dynamics & Tone（Warm Studio Amber `#E5A43B`）／Space（Titanium Ice `#5CC4E6`）** の3色に厳密分離し、詳細画面で23個のノブが同色に見えていた視認性課題を解消しました。
- **② アノダイズド暗色ハードウェアスイッチ ＆ 21分割CNCロータリーエンコーダ**：
  - まぶしいベタ塗りミント矩形スイッチを廃止し、**ダーク・フォージドカーボン筐体＋発光セマンティックリム＋LEDインジケータ**（主CTAのみブラッシュド・アンバー）に統一。左レール8モジュールも削り出しダークロッカースイッチへ刷新しました。
  - 全ロータリーダイヤルに **21分割精密マイクロスケール・バイポーラ0点センター刻み・アノダイズド面取りディッシュ** を導入し、絵文字に頼らない端正な機能表記へ統一しました。
- **③ 2D 音響ベクトル・クロスヘアパッド ＆ 総合画面『1クリック曲キー・スケール直結ピル』**：
  - 3Dワイヤーフレーム球体を廃し、極座標レンジリング・4象限活性アーク・BS.1770 LUFS / True Peak / Pocket ライブストリップを備えた **Carbon 2D Acoustic Vector Matrix** を搭載。
  - 総合画面「02 声をつくる」ヘッダに **`Key: 半音階▼`（1クリック曲キー・スケール選択＆8秒キー自動検出ピル）** を新設し、詳細画面へ移動せずその場で全24メジャー／マイナーキーおよび自動検出を切り替え可能にしました。
- **④ 詳細画面『Carbon Live Mastering & 6-Stage Signal-Budget Console』**：
  - 詳細画面右下の空き領域に **ITU-R BS.1770-4 K荷重 Short-Term LUFS / Momentary LUFS / True Peak (dBTP) / Crest Factor** の4連OLEDリードアウトと、**6系統リアルタイム活動量メーター（サ行保護・圧縮GR・小声浮上・艶リリーフ・倍音密度・Mポケット）** を統合しました。

## 2. 💎 『Carbon Vocal Engine』DSP信号経路の進化 ＆ 位相・バイパスバグ完全根治

- **① 超高域シルク空気感保護ディエッサー（`CarbonAirPreservingDeEsser`）**：
  - 従来の `6.5 kHz` ハイシェルフ・ディエッサーがサ行と一緒に削っていた **`11.8 kHz〜18.5 kHz` の無害な息の煌めき（Silk Air）** を位相整合スプリット回路で保護・復元。サ行の刺さりは強力に抑えたまま、ハイエンドコンデンサーマイクのような抜けと空気感を維持します。
- **② 歌唱中 M/S リバーブ・ボーカルポケット（`CarbonMsReverbPocket`）**：
  - 主旋律が存在する瞬間だけリバーブ残響の **Mid（センター）成分のみを最大 `-3.6 dB` 滑らかに掘り下げ**、同時に **Side（左右の広がり）を `+8%` 開放**。歌詞の子音・輪郭が一切濁らず最前面に立ち、フレーズ語尾では145msで自然に残響が開花します。
- **③ 多段エンハンサ統合調停器（`CarbonSpectralBudgetArbitrator`）＆ 1次ADAA無折り返し倍音**：
  - 3kHzプレゼンス系・超高域エアー系・小声アップワード系の多段モジュールが同時に重なった際の高域過多やリップノイズ浮上を防ぐブロック予算調停器を搭載（単体稼働時は無介入 `1.0x`）。
  - U87トランス飽和・パワフルロック倍音・Silk Air高域励起に **1次解析的アンチエイリアシング（1st-Order ADAA）＋ナイキスト保護LPF** を導入し、高域折り返し雑音を根絶しました。
- **④ 並列 Mix コムフィルタ・バイパス漏れ・Shimmer帰還遅延の完全修正**：
  - `Prism Mode 4` 内部の未報告3サンプル先読み遅延による `Mix=50%` 時の `8 kHz` 逆相打ち消しをゼロ遅延化により完全解消。
  - `Mix=0%`（原音100%）時のシンフォニック・ダブラー漏れ解消、`Mix<98%` 時のビブラート遅延コム干渉防止、`Shimmer` リバーブ帰還ループ前のプリディレイ配置適正化、およびモジュールOFF時のDe-Esser GRメーター即時ゼロ復帰を徹底しました。
