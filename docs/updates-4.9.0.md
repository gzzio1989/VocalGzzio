# VocalGzzio 4.9.0 の変更点（Starry Sky & Universal Style Edition）

公開日：2026年10月20日

## 1. 「星空・海・黄昏（Starry Sky, Sea & Twilight）」5大風景コレクション ＆ 天球水鏡オーブ
- 総合画面に5つの新しい風景・季節テーマ（Theme 14〜18）を搭載しました。中央カード右上の5つのピル（`01銀河`・`02碧海`・`03朝焼`・`04晩秋`・`05蒼劇`）または上部の「文字・見た目」からワンタッチで切り替えられます。
  - **01 銀河（Galactic Milky Way）**：星降る天の川銀河と蛍火の夜
  - **02 碧海（Lush Aqua Sea）**：エメラルド珊瑚礁と真珠の海
  - **03 朝焼（Radiant Dawn）**：黄金の朝焼けと水平線の光
  - **04 晩秋（Autumn & First Snow）**：紅葉の宵と初雪の調べ
  - **05 蒼劇（Opera Sapphire）**：サファイア歌劇場と黄金の天幕
- 中央の「天球水鏡オーブ」と下段3カードが黄金のアストロラーベ弧（Celestial Horizon）で結ばれ、歌声の倍音・残響に呼応して揺れる「水鏡32バンド・シンメトリック倍音リフレクション」や、マウス操作で広がるインタラクティブな水紋・流星・蛍火・紅葉＆初雪エフェクトを描画します（「⚡軽量」ON時は自動休止）。

## 2. 4つの「画面の見やすさ・操作スタイル切替」を新搭載
- 使う方の好みや作業環境に合わせて、画面のコントラスト・情報密度・案内表示を1クリックで切り替えられる4つのスタイルを搭載しました（総合画面右中段の切替バー、および上部「文字・見た目」ポップアップ内の両方に常設）。
  - **標準デザイン**：通常のテーマ配色・アニメーション・全コントロールを表示します。
  - **◉ くっきり大文字**：背景透けゼロの漆黒×純白（コントラスト比 12:1 以上・WCAG AAA準拠）、極太5px針、8分割大目盛り、特大太字、そして色だけに頼らない形状記号（`▼`削る・抑える / `▲`足す・揃える / `○`待機中）で小さな文字や目盛りを読みやすくします。
  - **★ かんたん3ステップ**：使用頻度の低いスイッチや背景の動きを整理し、「`STEP 1 雑音を消す ▶ STEP 2 声を揃える ▶ STEP 3 残響を足す`」の順路ガイド、各カードで最初に回すべきツマミの「`★まずここ`」ハイライト、待機中ツマミの減光で迷わず操作できます。
  - **● マット・具体表記**：ネオン発光・眩しい反射・グラデーション・点滅をすべて抑えたウォームスレート＆セージのマット配色と、水平グリッド整列、比喩を使わない具体的な機能名表記（`背景ノイズ除去`・`歯擦音(サ行)抑制`・`中高域(明瞭度)` など）に切り替えます。

## 3. 文字サイズ（80%〜150%）・UIサイズ（85%〜125%）全域での文字被り・見切れ防止
- すべてのラベル・ボタン・コンボボックス・直接描画テキストに縦横2軸の自動採寸（縦枠クランプ＋横幅自動フィット）を徹底しました。
- 文字サイズを最大（150%）に拡大した際や詳細画面（8列ノブ）を表示した際にも、数値カプセル（`-80.0 dB`・`100 Hz`・`120 ms` 等）、配信音量メーター、コンボボックスの未選択時テキスト、セクション見出しが枠線やツマミと重ならず、省略記号（`...`）を出さずに全文がくっきり読めるよう改善しました。

## 4. 仮想ドライバ（VocalGzzio Driver (WDM)）導入時のWindows既定デバイス自動保護
- インストーラーで専用仮想ドライバを新規登録した際、Windowsが勝手に既定の再生・録音デバイスを仮想ドライバへ切り替えてしまい `cluster` / `VRChat` / `Discord` の音が消える現象を防ぐため、導入前の実スピーカー・実マイク（Roland Rubix / Steinberg / YAMAHA AG 等）を自動記憶して即座に復元する保護機構を `VocalGzzioWdmInstaller` に搭載しました。
