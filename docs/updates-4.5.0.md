# VocalGzzio 4.5.0 変更記録

更新日：2026年10月16日。配布内容の再検査中です。実装の変更と、完成した配布ファイルの検証結果を分けて記録します。

## 声の輪郭を整える「声芯」

温かみ・空気感・広がりの調整に加え、「声芯」のバーを追加しました。中高域の成分を加えて、伴奏に埋もれがちな言葉の輪郭を調整します。入力の声量とサ行の強さに応じて加える量が変わります。強くかけると声が硬く感じられる場合があるため、少量から聴き比べてください。

中央のオーブと4本のバーでは、「倍音」「声芯」「空気」「立体」を操作できます。バーのダブルクリックはその項目を0％に、オーブのダブルクリックは4項目を0％に戻します。ブランド表示では対応する英語名を維持しています。

## 操作していない設定が変わる問題を修正

- 中央のオーブは4つの音色項目だけを動かすように整理しました。別の音色つまみや残響量を隠れて変更しません。
- 「仕上がり」を選んだ際に、自動でノイズを再学習したり、電源ノイズ除去を最大にしたりする処理を撤去しました。歌っている最中の音をノイズとして覚えてしまうことを防ぎます。
- 音量補助ボタンは、音が入っていないときに出力音量を変更しません。大きすぎる音を検出したときは、現在の出力音量を下げる方向にだけ調整します。下げ幅が足りない場合は入力音量を下げる案内を表示します。

## 声に合わせた初期設定

「声に合わせる」の自動調整では、測定した帯域バランスから4つの音色設定も提案します。これは測定値に基づく初期設定です。声質や曲に対する唯一の正解を決める機能ではないため、設定後は原音との比較と試奏で調整してください。

## 音量保護の説明を実装に合わせて修正

試作段階で追加されていたArgon内の天井処理を撤去しました。音色を操作しただけで急にピークが削られたり、ステレオの左右が異なる量だけ変形したりすることを避けます。

既存の音量保護は、大きな音で音量を緩やかに下げる補助です。瞬間的なピークをすべて止める仕組みではなく、サンプルの間に生じる「真のピーク」の測定・制限も行いません。以前の「音割れゼロ保証」などの説明は削除しました。

音量補助ボタンが使う目安の−14 dBFSは、その時点の出力ピークの値です。平均的な聞こえ方を測る−14 LUFSとは異なります。最も大きく歌う箇所で確認し、音声機器ですでに歪んでいる場合は入力ゲインから下げてください。

## 表示と引き継ぎ

4種類の総合画面配置と軽量表示を維持しています。軽量表示は画面の更新・装飾を減らし、音声処理の設定は変えません。既存のプロジェクトを開いただけで新しい音色設定へ置き換えません。

Macのアプリアイコン指定と、アイコン画像の同梱・導入後確認は継続します。製品版と体験版は別名で導入されます。WindowsとMacは同じ購入に含まれます。

## 配布検査の状況

4.5.0のファイル名を持つ既存の作業用ZIPについて、内側の版番号まで含めた再確認が必要な状態を確認したため、ソースから作り直して照合しています。ファイルの名称変更だけで更新済みとは扱いません。

確認項目は、本体とソースの版番号、製品版・体験版の一致、説明書、ZIPの破損、Macのインストーラー内容・両CPU対応・アイコン・AU読み込みです。自動検査の実行結果と配布物の完成状況は、確認後にこの項目へ追記します。
