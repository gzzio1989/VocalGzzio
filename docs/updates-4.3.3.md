# VocalGzzio 4.3.3

Macの単体起動アプリが汎用アイコンで表示される不具合を修正しました。アプリの作成時に既存のキャラクターアイコンを指定し、配布前とインストール後の検査でも同梱を確認します。音声処理は4.3.2と同じです。

協力者から、Apple M1搭載Macで4.3.2の単体起動と、REAPER上でのVST3読み込みの確認報告をいただきました。確認範囲はこの環境と形式です。Logic ProでのAU使用や、すべての機器・音声処理を検証したという意味ではありません。

Appleの正式な開発元署名・公証は未実施です。初回警告の可能性は残っています。更新前に録音ソフトと単体アプリを終了し、同梱の「ここから始める.html」から手順をご確認ください。
