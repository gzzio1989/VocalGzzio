# VocalGzzio 4.2

歌・話し声・アコースティックギターの音を整えるプラグインです。
入力から残響まで見渡せる総合画面と、細かく調整できる詳細画面を備えています。

[商品と体験版](https://gzzio.booth.pm/items/8764003) · [使い方](docs/manual.html)

## 最初の３ステップ

1. 入力の種類を選び、クリップしないよう入力音量を合わせます。
2. ６種類の「仕上がり」から目的に合うものを選びます。
3. 「押して原音と比較」で聴き比べ、音色・音量・残響を調整します。

ノイズがあるときは、黙った状態で学習してからノイズ除去を少しずつ上げます。
ノイズ処理を強くすると声も変化するため、常に最大にする機能ではありません。

## 4.2で見直したこと

- 総合画面を既定にし、入力・音色・空間を同時に見渡せる配置にしました。文字サイズ・画面サイズの調整、原音比較、独立したリバーブの入／切を用意しました。
- 目的から選ぶ６つの仕上がりを追加しました。自然、歌詞を前へ、丸く親密に、太く力強く、語り、広い余韻。従来の声・マイク・音色設定は詳細画面に残しています。
- ノイズ除去の帯域分割による音色の変化と、歌声で高域ノイズが戻る挙動を修正。学習データの扱いも改善しました。
- 音程のオクターブ誤検出、追従、移調時の位相と音量を見直しました。
- ギターチューナーは標準６弦、自動または弦指定、基準ピッチ調整に対応します。
- 空間IRリバーブは計算生成した６種類の残響データを使用します。実在の部屋を録音したデータではありません。停止後に古い残響が戻る問題と、サンプルレートで余韻が変わる問題を修正しました。
- ステレオの「のび」で左右の音量がずれる処理を修正しました。
- 体験版の構成変更で製品版を削除し得るインストーラーの指定を修正しました。
- ブランド表示の英語対応を保持しています。

## 音程と遅延について

音程補正・ハモリは、単独の歌声など音程が１つの音源を対象にしています。
声とギターが混ざった音を分離して補正する機能はありません。

音程処理を有効にすると、48kHzでは約42.6ミリ秒の処理遅延が加わります。
実際の値は画面に表示します。低遅延モードでは音程系を停止します。
音声機器・録音ソフト・通信による遅延は別に発生します。

合成音による自動検査は、実際の歌声やすべての録音ソフトでの動作を保証するものではありません。
体験版で、ご自身の声・機材・録音ソフトとの相性をご確認ください。

## 配布形式

- Windows 10 / 11、64ビット：VST3・単体起動アプリ。
- Mac：Apple Silicon / Intel向けVST3・AU・単体起動アプリの作成手順を同梱。配布開始は各配布ページをご確認ください。
- 体験版には一定間隔の音量低下があります。製品版と体験版は別の名前で導入されます。
- 電子署名・Macの公証は、各配布ページに記載された状態をご確認ください。

製品版はBOOTHの購入履歴から、体験版は無料配布欄から入手してください。
インストール前に録音ソフトと単体起動アプリを終了します。
既存のパラメータ番号を保ち、プロジェクトを開いただけで新しい仕上がりを自動適用することはありません。
音質不具合の修正による音の違いは生じます。

## 開発・検査

CMake 3.22以上、C++17、JUCE 8.0.12を使用します。
WindowsではVisual StudioのC++開発環境、MacではXcodeの開発環境が必要です。
Windowsの検査は tools/run_tests.ps1 で実行できます。

検査用ビルドは設定保存先を隔離します。配布には別のフォルダーで
VOCALGZZIO_BUILD_TESTS=OFF の本体を作り、梱包スクリプトで版番号と製品・体験の区別を検査してください。

公開の自動ビルドから取得できる配布物は体験版です。Mac製品版は公開鍵暗号で受け渡し、
秘密鍵と復号した製品版をリポジトリへ登録しません。
