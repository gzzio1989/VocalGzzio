# ボーカルグッジオ (VocalGzzio) — Vocal Channel Strip VST3

by **G'zzio**

歌・トーク配信用のリアルタイム・ボーカルチャンネルストリップです。
オンラインセッションや配信でそのまま使える **遅延0サンプル設計**（音程系の機能を使うときを除く）。

**ホームページ: https://gzzio1989.github.io/VocalGzzio/** （日本語 / English）

> **お知らせ**: アコグッジオ（AcoGzzio）は配信を終了しました。
> 今後の開発はボーカルグッジオ一本にまとめます。すでにお使いのアコグッジオは
> そのまま動きますが、更新とサポートは行いません。

## 主な機能
- **ピッチ補正（v1.9.0 で追加）**: 歌のピッチを検出してキー/スケール（9種）へ自動補正。
  フォルマントを保持するので声の性別感は変わりません。「速さ」でケロケロ〜自然を調整
- **プリセット**: 声質10種(女性5・男性5)× マイク特性20種(ライブ標準・放送ダーク・スタジオ定番など、ダイナミック/コンデンサーの傾向別)× シーン3種(弾き語り / トーク配信 / Band)を自由に掛け合わせ
- **ポップ/リップ除去 (v2.3.0)**: 「ぱ・ば行」の破裂音と、フレーズ間の口の粘着音を狙って抑制(歌っている最中は動きません)
- **ノイズ除去(DE-NOISE + LEARN)**: 4帯域の適応型。LEARN ボタンで部屋のノイズを約1.5秒学習(遅延ゼロ)
- **2段コンプ**(ピーク+平準化)、**ディエッサー**、ノイズゲート
- EQ(ローカット・こもり・キンキン・Presence・Air)、Warmth、**のび**(伸びる倍音)
- **声変え**: ピッチ/フォルマントを別々に操作、5人ユニゾン
- **ハモリ9種 (v2.0.0で大改修)**: 上下3度・上下6度・5度・3度+5度・おまかせ・**反行**(メロディと逆に動く対旋律)。
  **「ハモだけ」**で原音を消してハモリだけ別録りも可能
- **エモート (v2.0.0)**: 息(小声で息づかい)・エモ(ロングトーンで響きが開く)・サビリフト(サビ自動検出で盛り上げ)
- **MIDIスイッチ (v2.1.0)**: フットスイッチ/パッドに「ハモだけ」「ひびきON/OFF」「A/B切替」など12種を割当(8枠)
- **配信出力 (v2.2.0・単体起動版)**: 処理後の音をヘッドホンとは別の出力先へ同時送出。VB-CABLE 等を経由して OBS へ
- Width / ダブラー / ディレイ / リバーブ(スプリング・シマー含む)
- キー・コード進行の解析、チューナー(基準ピッチ可変)、IN / OUT / GR / DS / DN メーター
- A/B比較、プリセット保存/読込、「文字を大きく」ボタン、画面モード切替
- 全ツマミに【効果】と【伝わり方】の2段説明(カーソルを合わせると表示)

## 動作環境
- Windows 10 / 11 (64bit)
- VST3 対応 DAW(REAPER, SONAR, Cubase 等)。単体起動できる Standalone 版も同梱
- Mac 版は GitHub Actions で自動ビルドしていますが、**未署名・未検証**です

## インストール
**方法A(推奨): インストーラー**
1. Releases から `VocalGzzio_Setup_vX.X.X.exe` をダウンロードして実行
2. 初回起動時に SmartScreen の青い警告が出た場合は
   **「詳細情報」→「実行」** で進めてください(未署名のためで、異常ではありません)
3. DAW を再起動し、FX 追加で「VocalGzzio」を検索

インストーラーでは **VST3 プラグイン** と **単体起動アプリ** を選んで入れられます。
すでに入っている状態で実行すると、最初に次の4つから選べます。

| 選択 | 何をするか |
|------|-----------|
| **更新** | 今の構成のまま、新しいバージョンに入れ替える |
| **修正** | 消えた・壊れたファイルを同じバージョンで入れ直す |
| **追加・変更** | VST3 / 単体起動版のうち、入れるものを選び直す（外したものは削除されます） |
| **削除** | アンインストールする |

**方法B: 手動コピー**
`VocalGzzio.vst3` フォルダを `C:\Program Files\Common Files\VST3\` にコピー → DAW を再起動。

## 使い方のコツ
1. 上のコンボで「声質」と「マイク」を選ぶ(下のシーンも)
2. 黙った状態で **LEARN** を押して1.5秒待つ → DE-NOISE を上げるとノイズが消えます
3. 歌うならTONEの「のび」を上げるとロングトーンが伸びて聴こえます
4. 音程を直したいときは、エフェクト(声)タブの **ピッチ補正** を ON。
   キーが分からなければ「キー検出」を押すと自動で入ります。補正80% / 速さ30% が目安

## 配信ソフト(OBS等)に音を送るには
**方法A(かんたん・追加ソフト不要)**: 単体起動版の出力を ASIO ではなく「Windows Audio」にして、
OBS の **「アプリケーション音声キャプチャ」**で `VocalGzzio.exe` を選ぶ。
※ ASIO で出している音はこの方法では拾えません。

**方法B(ASIO でモニターしたまま配信する)**: **配信出力**を使います。
1. 仮想オーディオデバイスを入れる（**VB-CABLE**が定番 https://vb-audio.com/Cable/ ）
2. 「こだわり」→「エフェクト」タブ → 右下の **「配信出力」**
3. 配信先に `CABLE Input` を選び「配信に送る」
4. OBS で「音声入力キャプチャ」を追加し `CABLE Output` を選ぶ

自分の声はヘッドホンで聴いたまま、加工済みの声が配信に乗ります。

## ソースからビルドする場合
Visual Studio 2022(C++ デスクトップ開発)+ CMake 3.22 以上 + Git が必要です。
JUCE 8.0.12 は CMake が自動で取得するので、事前準備は要りません。

```
git clone https://github.com/gzzio1989/VocalGzzio.git
cd VocalGzzio
cmake -B build -A x64
cmake --build build --config Release
```

出力:
- `build\VocalGzzio_artefacts\Release\VST3\VocalGzzio.vst3`
- `build\VocalGzzio_artefacts\Release\Standalone\VocalGzzio.exe`

macOS / Linux:

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 4
```

インストーラーを作るには、ビルド後に `Installer.iss` を Inno Setup 6 で開いて Compile。
`installer_output\` に出来上がります。
（`Installer.iss` は **UTF-8 BOM付き** で保存してください。BOM が無いと日本語が化けます）
