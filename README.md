入力から残響まで見渡せる総合画面（4種の画面構造と2D声質重力場オーブ）と、細かく調整できる詳細画面を備えています。

## 最初の３ステップ

1. 入力の種類を選び、クリップしないよう入力音量を合わせます。
2. ６種類の「仕上がり」または中央の「Argon 2D 声の重力場オーブ」から目的に合うものを選びます。
3. 「押して原音と比較」で聴き比べ、音色・音量・残響を調整します。

ノイズがあるときは、黙った状態で学習してからノイズ除去を少しずつ上げます。
ノイズ処理を強くすると声も変化するため、常に最大にする機能ではありません。

## 画面と音づくり（4.4.0 新機能）

- **Argon Velvet Engine（独自倍音・空気感・立体空間DSP）**：母音とサ行のエネルギー比をリアルタイム追跡し、サ行を一切ザラつかせずに母音へ非対称三極管2次倍音と135Hz胸鳴りを加える「VELVET」、クレストファクタ保護つき14kHz空気感の「SILK AIR」、スマホのモノラル再生でも位相キャンセリングゼロの直交オールパス拡散「3D BINAURAL HALO」を新搭載。
- **Argon 2D 声の重力場オーブ ＆ 4つのVoice DNAターゲット**：画面中央の2Dオーブをドラッグするか、4つのターゲット（★VELVET歌枠／♥ASMRささやき／✦CRYSTALポップス／◆HALOバラード）を選ぶだけで、倍音・空気感・立体空間を直感的に同時成形できます（ダブルクリックで0%へリセット）。
- **4種のワークスペース画面構造**：画面上部の `[★ARGON / ♥LIVER / 🎛STUDIO / ◎従来]` ピルで、3ウイング・コックピット、配信・Vライバー特化12連マカロンステージ、5列ハードウェア・チャンネルストリップ、従来配置をワンクリックで切り替えられます。
- **ワンクリック省負荷「⚡軽量モード（ECO LITE）」**：音声DSP品質は100%最高品質のまま、4096点FFTスペクトラム・背景パーティクル・半透明ガラス合成を休止し、配信中やノートPCでのGPU/CPU負荷を極小化します。
- 目的から選ぶ６つの仕上がり、ノイズ学習・除去、標準６弦ギター／４弦・５弦ベース対応チューナー、空間IRリバーブ、ブランド英語表示を備えています。

## 音程と遅延について

音程補正・ハモリは、単独の歌声など音程が１つの音源を対象にしています。
声とギターが混ざった音を分離して補正する機能はありません。

音程処理を有効にすると、48kHzでは約42.6ミリ秒の処理遅延が加わります。
実際の値は画面に表示します。低遅延モードでは音程系を停止します。
音声機器・録音ソフト・通信による遅延は別に発生します。

合成音による自動検査は、実際の歌声やすべての録音ソフトでの動作を保証するものではありません。
体験版で、ご自身の声・機材・録音ソフトとの相性をご確認ください。

## 配布形式

- Windows 10 / 11、64ビット：VST3・単体起動アプリ。
- Mac：macOS 11以降、Appleシリコン／Intel両対応。VST3・AU・単体起動アプリとインストーラーを同梱。
- 体験版には一定間隔の音量低下があります。製品版と体験版は別の名前で導入されます。
- MacのApple開発者署名・公証、Windowsインストーラーの電子署名は未付与です。Mac実機での導入・録音ソフトでの試奏は未確認です。Windows・Macとも自動検査51項目に合格しています。

製品版はBOOTHの購入履歴から、体験版は無料配布欄から入手してください。
インストール前に録音ソフトと単体起動アプリを終了します。
既存のパラメータ番号を保ち、プロジェクトを開いただけで新しい仕上がりを自動適用することはありません。
音質不具合の修正による音の違いは生じます。

## 開発・検査

CMake 3.22以上、C++17、JUCE 8.0.12を使用します。
WindowsではVisual StudioのC++開発環境、MacではXcodeの開発環境が必要です。
Windowsの検査は tools/run_tests.ps1 で実行できます。

検査用ビルドは設定保存先を隔離します。配布には別のフォルダーで
VOCALGZZIO_BUILD_TESTS=OFF の本体を作り、梱包スクリプトで版番号と製品・体験の区別を検査してください。

公開の自動ビルドから取得できる配布物は体験版です。Mac製品版は公開鍵暗号で受け渡し、
秘密鍵と復号した製品版をリポジトリへ登録しません。
