## 最初の3ステップ

1. 入力の種類を選び、いちばん強く歌うところで入力が歪まないよう音声機器の音量を合わせます。
2. 「声に合わせる」の自動調整か「仕上がり」を選びます。中央のオーブや4本のバーで、温かみ・声の輪郭・空気感・広がりを調整できます。
3. 「押して原音と比較」で聴き比べ、出力音量と残響を仕上げます。音量補助ボタンは、声を出している間の出力ピークを目安に音量を調整します。

ノイズがあるときは、黙った状態で「ノイズを測る」を押し、学習後にノイズ除去を少しずつ上げます。強くかけると声や息も変化するため、最大値を常用するための機能ではありません。

## 4.5.0の音づくりと操作改善

- **声の輪郭を調整する「声芯」**：中高域を加えて、言葉を聞き取りやすくするための調整です。声量やサ行の強さに応じて加える量を抑えます。明るすぎる声には少量から使います。
- **動かした項目が分かる4本の音色バー**：「倍音」は温かみ、「声芯」は言葉の輪郭、「空気」は高域の息づかい、「立体」はステレオの広がりを調整します。中央のオーブはこの4項目をまとめて動かし、別の音色・残響つまみは動かしません。
- **学習したノイズを保持**：「仕上がり」を選んだだけでノイズ学習をやり直したり、電源ノイズ除去を最大にしたりしません。音色を試すときも、測定済みのノイズ設定を使い続けられます。
- **声の分析に合わせた初期設定**：自動調整では入力音の帯域バランスから4本の値も提案します。設定後は歌声を聴いて調整してください。声と伴奏を分離する機能ではありません。
- **無音で音量を変えない補助ボタン**：計器盤の音量ボタンは、その時点の出力ピークから出力音量を補正します。音が入っていないときは設定を変えません。出力音量を下げても大きすぎる場合は、入力音量を下げる案内を表示します。
- **4種類の配置と軽量表示**：中央の音色調整を大きく見せる配置、配信用の横並び、録音用の縦列、従来の3カードから選べます。「軽量」は表示の更新や装飾を減らします。音声処理の設定は変わりません。

音量保護は大きな音で音量を緩やかに下げる補助です。瞬間的なピークをすべて止める機能ではありません。マイクや音声機器ですでに歪んだ入力を元に戻すこともできません。最も大きく歌う箇所で出力を確認してください。

## 音程と遅延について

音程補正・ハモリは単独の歌声など、音程が1つの音源を対象にしています。声とギターが混ざった音を分離して補正する機能はありません。

音程処理を有効にすると、48kHzでは約42.6ミリ秒の処理遅延が加わります。現在の値は画面に表示します。低遅延モードでは音程系を停止します。音声機器・録音ソフト・通信による遅延は別に発生します。

## 配布形式と確認範囲

- Windows 10 / 11、64ビット：VST3・単体起動アプリ。
- Mac：macOS 11以降、Appleシリコン／Intel用。VST3・AU・単体起動アプリをインストーラーで導入します。
- 製品版と体験版は別の名前で導入されます。体験版は60秒ごとに0.6秒だけ音量が下がり、設定ファイルの保存・読込は使えません。
- MacのApple開発者署名・公証、Windowsインストーラーの電子署名は未付与です。Macの `.component` は録音ソフトが読む部品です。導入には `.pkg`、単体起動には導入済みの `.app` を使ってください。

4.3.2では、協力者のM1 Macで単体起動アプリとREAPERのVST3の動作報告を受けています。この報告は4.5.0の実機検証や、すべてのMac・録音ソフトでの動作確認を意味しません。4.5.0の配布前検査の結果は変更記録へ反映します。合成音による自動検査と、実際の歌声・音声機器での試奏は別に扱います。

製品版はBOOTHの購入履歴から、体験版は無料配布欄から入手してください。インストール前に録音ソフトと単体起動アプリを終了します。既存のパラメータ番号を保ち、プロジェクトを開いただけで新しい仕上がりを自動適用することはありません。音質修正による音の違いは生じるため、大事なプロジェクトと更新前の音を書き出して保管してください。

## 開発・配布物の作成

CMake 3.22以上、C++17、JUCE 8.0.12を使用します。WindowsはVisual StudioのC++開発環境、MacはXcodeの開発環境が必要です。

Windowsの検査は `tools/run_tests.ps1` で実行します。検査用ビルドは設定保存先を隔離します。配布用は別フォルダーで `VOCALGZZIO_BUILD_TESTS=OFF`・`VOCALGZZIO_LITE=OFF` を指定し、製品版と体験版も分けてビルドしてください。

Windowsのインストーラーは `tools/package_windows.ps1`、説明書を含むZIPは `tools/package_windows_archive.py` で作成します。前者は版番号・製品名・製品と体験の目印・検査用保存先の混入を照合し、既存配布物の上書きを拒否します。Macは `tools/package_macos.py` をMac上で使い、ソースと本体の版、2種類のCPU、アイコンを照合します。使い捨てのMac検査環境では `--validate-install` でインストーラー導入とAU読み込みを確認します。

公開の自動ビルドから取得できる配布物は体験版です。Mac製品版は公開鍵暗号で受け渡します。秘密鍵、復号した製品版、個人情報を含む画像をリポジトリや公開成果物へ登録しないでください。
