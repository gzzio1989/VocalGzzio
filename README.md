## 最初の3ステップ

1. 入力の種類を選び、いちばん強く歌うところで入力が歪まないよう音声機器の音量を合わせます（マイクが `IN 1〜IN 4` のどこに挿さっていても、自動で両耳中央 `L=R` に揃えます）。
2. 「うた自動」の自動調整か「仕上がり」、または「🎵 BGM・録音」の **5秒声質ターゲット診断** を選びます。中央のオーブや4本のバーで、温かみ（倍音）・声の輪郭（声芯）・空気感（空気）・広がり（立体）を調整できます。
3. `🔄5秒試聴` で自分の声を5秒録ってループ再生しながら、「押して原音と比較」で聴き比べ、出力音量と残響を仕上げます。配信本番中は **`📌 ミニバー`** に切り替えて画面の隅に置くか、裏画面ホットキー（`Ctrl+Shift+M` / `F9` 咳ミュート等）で快適に進められます。
